# ブランド体験創造部：2026年度 実戦戦略マップ（組織実態準拠）

## 1. 大目標 (Goal)
**「指名買い」されるブランドへの進化と、顧客生涯価値（LTV）の最大化**
- **財務責任**: インセンティブ（値引き原資）の抑制による限界利益の改善
- **経営指標**: 3年後残価率の維持向上、再購入意向（リピート率）の向上

## 2. 実戦的タスク分解 (Task Breakdown)

### 2.1. A: カスタマー・エクスペリエンス（CX）の高度化
- **A-1. デジタル接点の融合 (MyMazda連携)**:
    - 車両データ（コネクティッド）を活用したパーソナライズ点検予約の自動化。
    - アプリ内での「走る歓び」体験ログの可視化。
- **A-2. 次世代店舗体験（マツダWay店舗）の標準化**:
    - 新しい店舗デザインガイドラインに基づく、全国販売店の「体験価値」監査。
    - セールススタッフ向け「ブランド・エバンジェリスト」育成プログラムの展開。

### 2.2. B: バリューチェーン・ブランディング
- **B-1. リセールバリュー管理戦略**:
    - 国内・北米市場における中古車オークション価格のリアルタイム監視と、流通量調整。
    - 下取り価格保証制度の精緻化による「マツダ車は値落ちしない」という信頼の構築。
- **B-2. 認定中古車 (CPO) のブランド再定義**:
    - プレミアムブランドに匹敵するCPO保証プログラムの設計とローン商品の開発。

### 2.3. C: エンゲージメント・マーケティング
- **C-1. オーナーコミュニティの活性化 (ファンベース)**:
    - 「マツダファンフェスタ」等のイベントと、オンラインコミュニティの相互送客設計。
    - 開発エンジニアとオーナーが直接対話する「知見共有イベント」の企画。
- **C-2. 独自技術の「体験」への変換**:
    - 「人馬一体」や「魂動デザイン」を、単なる言葉ではなく、試乗や接客で「体感」させるための評価指標（官能評価）の導入。
