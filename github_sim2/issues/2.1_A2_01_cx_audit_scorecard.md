# Issue #2.1-A2-01: 次世代マツダ店舗向け「CX監査（Audit）」スコアカードの開発

## 1. 背景 (Context)
店舗デザイン（ハード）だけでなく、接客や試乗体験（ソフト）の質を全国で均一化し、ブランド価値を担保するための定量的な評価基準が必要。

## 2. 具体的タスク (Tasks)
- [ ] 既存の顧客満足度調査（CSI）に代わる、「ブランド体感度」を測る質問項目の作成
- [ ] 試乗コースにおいて「人馬一体」を最も体感できるスポットを指定するガイドラインの策定
- [ ] 店舗スタッフの「マツダ愛」と「知識量」を認定するエバンジェリスト制度の評価基準策定
- [ ] デジタルと店舗の連携（アプリ予約から来店までのスムーズさ）の評価ロジック構築

## 3. 成功の定義 (Definition of Done)
- 全国の販売店が「自店の弱点」を一目で把握できるダッシュボード形式のスコアカード案が完成すること。
