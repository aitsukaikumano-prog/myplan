# Issue #2.1-A1-02: 「走る歓び」を可視化するドライブログ体験のUI/UX設計

## 1. 背景 (Context)
マツダ車の価値は「運転中の心地よさ」にあるが、これを所有後もアプリで見返すことができれば、ブランドへの愛着（エンゲージメント）が深化する。

## 2. 具体的タスク (Tasks)
- [ ] Gベクタリングコントロール等の制御介入度を「滑らかな運転スコア」として算出するアルゴリズム案
- [ ] ドライブしたルートと景色の思い出を紐付けるフォトログ機能の画面遷移図作成
- [ ] 他のオーナーと「走り」の知見を共有できるコミュニティ機能のコンセプト設計
- [ ] 燃費性能だけでなく、いかに「楽しく走ったか」を評価する新指標の定義

## 3. 成功の定義 (Definition of Done)
- オーナーが「毎日開きたくなる」アプリ画面のプロトタイプ（Figma等）が承認されること。
