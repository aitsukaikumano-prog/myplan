# Issue #2.3-C1-01: マツダファンフェスタ連携型オンラインコミュニティの相互送客設計

## 1. 背景 (Context)
リアルのイベント（ファンフェスタ）とデジタルのコミュニティをシームレスに繋ぎ、イベント終了後も熱量を維持し続ける「循環型」のファン形成を目指す。

## 2. 具体的タスク (Tasks)
- [ ] イベント会場での「チェックイン」をトリガーとした限定デジタルコンテンツの配布設計
- [ ] 開発エンジニアとオーナーが日常的に交流できる「技術相談BBS」の運営ルール策定
- [ ] ファン同士が自発的にオフ会を企画できるプラットフォーム機能の要件定義
- [ ] 貢献度の高いファン（アンバサダー）を可視化し、インセンティブを与える仕組みの構築

## 3. 成功の定義 (Definition of Done)
- 次回ファンフェスタにおいて、参加者の50%以上がオンラインコミュニティに新規登録またはアクティブ化すること。
