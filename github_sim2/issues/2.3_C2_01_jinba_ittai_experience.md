# Issue #2.3-C2-01: 試乗体験における「人馬一体」官能評価指標の導入とマニュアル化

## 1. 背景 (Context)
「人馬一体」という抽象的な言葉を、顧客が納得できる「体感」に落とし込む。試乗中に何に注目し、どう感じればよいのかを言語化・定量化する。

## 2. 具体的タスク (Tasks)
- [ ] 加速度のつながり（Gジャーク）の滑らかさを「心地よさ」として説明する接客トークの開発
- [ ] 試乗前後の心拍数や表情変化など、生体反応を用いた「ワクワク度」の簡易測定実験
- [ ] 全国の試乗コースにおける「マツダの良さが最も分かるコーナー」の選定基準作成
- [ ] 試乗後に顧客が自身の感覚をフィードバックする「官能評価シート」の設計

## 3. 成功の定義 (Definition of Done)
- 試乗後の成約率（または再来店率）が、新指標導入前のパイロット店舗で15%以上向上すること。
