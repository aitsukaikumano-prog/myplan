## 📝 議事内容

### 1. 既存CSI（顧客満足度指標）の課題整理

**発言者**: @ito (営業本部)
**内容**:
- 現行CSIは「対応の丁寧さ」「説明のわかりやすさ」など一般的な項目
- マツダらしさ、ブランド価値の体感度は測定できていない
- 競合他社と差別化できる指標が必要

**発言者**: @nakamura (品質管理部)
**内容**:
- 店舗間のバラつきが大きい（特に試乗体験）
- 標準化のためにも定量的な基準が必要

### 2. 新指標「ブランド体感度」の定義

**議論内容**:

| 既存CSI | 新・ブランド体感度 |
|---------|------------------|
| 「説明がわかりやすかった」 | 「マツダの技術の凄さが伝わった」 |
| 「対応が丁寧だった」 | 「自分のことを理解してくれた」 |
| 「試乗ができた」 | 「運転する楽しさを体感できた」 |

**決定事項**:
- 「機能的満足」から「情緒的満足」への転換を目指す
- 5段階評価ではなく、NPS形式（0-10点）で測定

### 3. 試乗体験における評価ポイントの議論

**発言者**: @mika
**内容**:
- 試乗コースに「人馬一体体感スポット」を設定したい
- 例: S字カーブ、緩やかな坂道、高速合流
- スタッフが「ここで◯◯を感じてください」と案内

**ワークショップ成果**:

| 体感スポット | 感じてほしいこと | 推奨トーク |
|------------|----------------|-----------|
| S字カーブ | ハンドルの一体感 | 「手を添えるだけで曲がる感覚」 |
| 坂道発進 | トルクの滑らかさ | 「アクセルを踏んだ瞬間の応答」 |
| 直線加速 | エンジンの静粛性 | 「この速度でこの静けさ」 |

### 4. スコアカードの項目案作成

**決定事項**:

**A. 店舗環境（ハード）** - 20点満点
- 清潔感・整理整頓
- マツダらしい空間演出
- 試乗車の状態

**B. 接客体験（ソフト）** - 40点満点
- ブランドストーリーの伝達力
- 顧客ニーズの傾聴力
- 押し売り感のなさ

**C. 試乗体験** - 40点満点
- 体感スポットでの案内
- 運転の楽しさの共有
- 試乗後のフォロー
