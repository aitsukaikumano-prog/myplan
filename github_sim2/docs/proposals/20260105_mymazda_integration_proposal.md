# 提案書: MyMazdaアプリ連携による顧客体験向上施策

**作成日**: 2026-01-05
**作成者**: @daiki
**ステータス**: レビュー中

---

## 概要

MyMazdaアプリと販売店システムを連携し、来店前に顧客の車両状態を把握することで、パーソナライズされたサービス提案を実現する。

---

## 背景と課題

### 現状の課題
- 顧客来店時に車両状態を把握するのに時間がかかる
- 整備履歴が店舗間で共有されていない
- 「お客様が言う前に気づく」サービスができていない

### 競合状況
- トヨタ: T-Connect連携済み
- 日産: NissanConnect連携済み
- マツダ: MyMazdaと店舗システムが未連携

---

## 提案内容

### 1. リアルタイムデータ連携
- 車載コネクティッドユニットから走行距離、バッテリー状態、油脂類劣化度を取得
- 1日1回のバッチ処理で販売店CRMに反映

### 2. プロアクティブ提案機能
- 次回点検時期の自動通知
- 消耗品交換の事前提案
- リコール情報の即座な共有

### 3. 来店時ダッシュボード
- 担当者向けに顧客の車両状態をワンページで表示
- 推奨サービスメニューを自動生成

---
