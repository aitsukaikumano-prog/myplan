### 新プログラムの主なポイント

1. **認定基準の厳格化**
   - 100項目以上の点検
   - 走行距離制限の見直し
   - 年式制限の緩和（7年→10年）

2. **保証の充実**
   - 保証期間を2年から3年に延長
   - 全国どの販売店でも保証対応可能

3. **デジタル化**
   - 車両履歴のオンライン閲覧
   - バーチャル内覧機能
   - オンライン商談対応
