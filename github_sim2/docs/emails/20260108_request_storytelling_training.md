## 本文

山田部長

お疲れ様です。販売店支援部の中村です。

ブランド価値向上プロジェクトの一環として、販売店スタッフ向け「ブランド・ストーリーテリング研修」の予算申請をさせていただきます。

### 研修の目的

マツダのブランドストーリー（人馬一体、走る歓び）を販売店スタッフが自分の言葉で顧客に伝えられるようになることを目指します。

現状の課題：
- スペック説明に偏りがちな接客
- ブランド価値を伝える言葉の不足
- 競合との差別化ポイントの理解不足

### 研修概要

| 項目 | 内容 |
|------|------|
| 対象者 | 全国販売店のセールススタッフ（約2,000名） |
| 形式 | 動画研修 + オンラインワークショップ |
| 期間 | 2026年3月〜6月（4ヶ月間） |

### 予算内訳

| 項目 | 金額 |
|------|------|
| 研修動画制作（15本） | 450万円 |
| オンラインWS運営（20回） | 200万円 |
| 教材・資料作成 | 100万円 |
| 講師謝礼 | 50万円 |
| **合計** | **800万円** |

### 期待効果

- 顧客満足度調査での「ブランド理解」スコア 20%向上
- 試乗から成約への転換率 5%改善
- スタッフのブランドへの愛着・誇り向上

### スケジュール

- 1月: 予算承認、制作会社選定
- 2月: コンテンツ制作
- 3月: 研修開始（第1期）
- 6月: 全店舗展開完了
