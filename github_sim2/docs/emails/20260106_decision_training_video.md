中村様

お疲れ様です。人事部 教育研修課の森本です。

先日ご依頼いただいた販売店向け研修動画の制作について、部内で検討した結果、承認となりましたのでご連絡いたします。

### 承認内容

| 項目 | 内容 |
|------|------|
| 制作本数 | 全15本（基礎編5本、実践編10本） |
| 制作予算 | 450万円（見積り通り） |
| 制作期間 | 2026年2月〜3月 |
| 納品予定 | 2026年3月末 |

### 承認条件

1. **ブランドガイドライン準拠**
   - 動画内で使用するロゴ、カラー、フォントはブランドガイドラインに従うこと
   - 制作開始前にデザイン部門のチェックを受けること

2. **内容の事前確認**
   - 各動画の絵コンテを人事部・販売店支援部で事前確認
   - 完成版は社内テスト視聴を経てから配布

3. **効果測定の実施**
   - 研修受講後のテストを実施し、理解度を測定
   - 3ヶ月後に現場での行動変容を確認

### 今後の進め方

1. 1月10日（金）までに制作会社3社から最終見積りを取得
2. 1月15日（水）に制作会社選定会議を開催（ご参加ください）
3. 1月20日（月）に制作キックオフ

制作会社選定の際は、マツダブランドへの理解度を重視してください。
過去の自動車関連実績があれば優先的に検討をお願いします。

ご不明点があればお気軽にお問い合わせください。
