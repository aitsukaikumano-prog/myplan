CPOブランド再定義プロジェクトに関連して、北米市場におけるリセールバリュー調査の実施について承認をお願いしたくご連絡いたしました。

### 調査の背景

国内市場のリセールバリュー分析（岡田さんレポート参照）が完了し、グローバル展開を見据えた北米市場の調査が必要となっています。

北米市場は以下の点で重要です：
- マツダの主要市場（販売台数の約35%）
- CPOプログラムが成熟している市場
- 競合他社との比較が明確

### 調査概要

| 項目 | 内容 |
|------|------|
| 調査対象 | 北米市場（米国・カナダ） |
| 調査期間 | 2026年1月〜2月（8週間） |
| 調査手法 | 市場データ分析 + ディーラーインタビュー |
| 外部委託先 | J.D. Power（候補） |

### 調査項目

1. **定量調査**
   - 車種別残価率（3年/5年）
   - 競合他社との比較分析
   - 地域別の価格動向

2. **定性調査**
   - ディーラーインタビュー（10社）
   - 消費者フォーカスグループ（3回）
   - CPO購入者アンケート（n=500）

### 期待される成果

- 北米CPO戦略への示唆
- グローバル統一ブランド戦略への貢献
- 日本市場への逆輸入可能な施策の発見
