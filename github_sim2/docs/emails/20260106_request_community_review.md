ファンコミュニティプラットフォームの設計が完了しましたので、レビューをお願いしたくご連絡いたしました。

### レビュー対象

**ファンコミュニティプラットフォーム「MAZDA SPIRIT CLUB」（仮称）**

本プラットフォームは、マツダファンの皆様が交流し、ブランドへの愛着を深めていただくためのオンラインコミュニティです。

### 主要機能

1. **オーナーズプロフィール**
   - 愛車情報の登録・公開
   - カスタマイズ・メンテナンス履歴の共有
   - ドライブログの投稿

2. **フォーラム機能**
   - 車種別コミュニティ
   - 地域別コミュニティ
   - イベント情報掲示板

3. **イベント連携**
   - オフラインイベントの告知・参加登録
   - オンラインミーティングの開催
   - ファンミーティングの運営支援

4. **特典プログラム**
   - 活動ポイントの付与
   - 限定グッズ交換
   - ディーラー特典の提供

### 技術スタック

| 項目 | 採用技術 |
|------|----------|
| フロントエンド | React + TypeScript |
| バックエンド | Node.js + Express |
| データベース | PostgreSQL |
| 認証 | OAuth 2.0（MyMazda連携） |
| ホスティング | AWS |
