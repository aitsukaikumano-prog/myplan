CPOブランド再定義プロジェクトに関連して、リセールバリュー分析レポートを提出いたします。

### エグゼクティブサマリー

国内中古車市場におけるマツダ車のリセールバリューについて、競合他社との比較分析を実施しました。

**主要な発見：**
- マツダ車の3年後残価率は平均52%（業界平均55%）
- CX-5は競合SUVと同等の残価率を維持
- ロードスターは特殊カテゴリとして高残価率（68%）

### 詳細分析結果

#### 車種別残価率（3年後）

| 車種 | マツダ | 競合平均 | 差分 |
|------|--------|----------|------|
| CX-5 | 58% | 57% | +1% |
| CX-30 | 54% | 56% | -2% |
| MAZDA3 | 48% | 52% | -4% |
| ロードスター | 68% | N/A | - |

#### 残価率に影響する要因

1. **ブランドイメージ** - 「プレミアム感」の認知度が残価に直結
2. **品質信頼性** - 故障率の低さが中古車市場で評価
3. **デザイン持続性** - 古さを感じさせないデザインが重要
4. **アフターサポート** - CPO保証の充実度

### 提言

1. **CPO認定基準の厳格化** - プレミアム感の醸成
2. **保証期間の延長** - 競合との差別化（現行2年→3年）
3. **認定中古車専用サイトの刷新** - デジタル顧客体験の向上
