# 商品戦略部：2026年度 モデル価値向上プロジェクト

## 1. 上位組織（経営）からのミッション
- **リセールバリュー（3年残価率）の 5% 向上**
- **値引き（販売インセンティブ）の 30% 削減**

## 2. 部の方針：WTP（支払い意欲）重視型・商品改良
「エンジニアのこだわりを、顧客の『財布が開く価値』へと変換し、一台あたりの限界利益を最大化する」

## 3. 重点プロジェクト：価値実証 5大プロトタイプ
1. **感性価値の定量化（デザイン）**
2. **デジタル体験の統合（コネクティッド）**
3. **走りの質感の再定義（ダイナミクス）**
4. **持続可能なラグジュアリー（マテリアル）**
5. **所有体験のDX（サービス・アプリ）**
