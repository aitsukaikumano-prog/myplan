# マツダ再興：全社上位方針 (Strategic Core)

## 1. パーパス (Purpose / Mission)
「前向きに今日を生きる人の輪を広げる」
- **魂の定義**: マツダが存在する究極の理由。移動を通じて、人生の輝きを最大化する。

## 2. 戦略エンジン (Strategic Engine / Business Goals)
### 目標: 営業利益のV字回復 (Δ +1,500億円の改善)
- **経営レバー A: 固定費の構造的削減 (-1,000億円)**
    - R&D費（年間1,800億円）および販管費の効率化による原資創出。
- **経営レバー B: 限界利益の最大化 (+500億円)**
    - 顧客の支払い意欲（WTP）にフォーカスした価値向上と値引き抑制。

## 3. 論理の接続 (Logic Connection)
「収益がなければ、人の輪を広げるための次世代技術も、所有体験も持続できない。今、我々はムダを削ぎ落とし、存続の力を蓄えるフェーズにある。」

## 4. 2026年度 重点実施事項
- **R&D現場の同期（Sync）による「死に金」の撲滅**
- **市場適合性の強制同期による単価プレミアムの防衛**
