# Issue #001: 図面検索工数の削減によるR&D固定費の圧縮

## 1. 解決すべき課題 (Problem)
マツダの開発現場において、過去の設計図面や知見の検索に、エンジニア一人あたり週平均5時間が費やされている。これはR&D費1,800億円のうち、約10%（180億円分）の工数が「探し物」という非付加価値作業に消えていることを意味する。

## 2. 成功の定義 (Definition of Done)
- [ ] 現場エンジニア（佐藤工場長等）へのヒアリングによる「検索の痛み」の具体化
- [ ] AIプロトタイプによる検索時間の50%削減の証明
- [ ] 全社展開に向けた投資対効果（ROI）の算出
