## 詳細説明

熊野町および近隣地域で開催されている勉強会・交流会を調査し、
AIコミュニティの参考にする。また、参加して接点を作る候補を見つける。

### 目的

- 既存コミュニティの活動内容・運営方法を学ぶ
- 競合・類似のAI勉強会がないか確認する
- 参加して人脈を広げる候補を見つける

### 作業内容

1. 熊野町内の勉強会・交流会を調査
2. 広島市・呉市・東広島市のIT/AI勉強会を調査
3. 商工会主催のセミナー・イベントを調査
4. 各イベントの開催頻度・参加者層を整理
5. 参加候補リストを作成

---

## 調査対象

### 熊野町内
- 商工会主催のセミナー・勉強会
- 筆の里工房のイベント
- 地域の異業種交流会

### 広島市
- IT系勉強会（connpass、Doorkeeper等で検索）
- 広島AIコミュニティ（あれば）
- 起業家・スタートアップ系イベント

### 呉市・東広島市
- 商工会議所主催イベント
- 地域の勉強会

### オンライン
- 広島発のオンライン勉強会
- 全国のAI/IT勉強会（参考）

---

## 調査項目

| 項目 | 内容 |
|------|------|
| 名称 | 勉強会・交流会の名前 |
| 主催 | 主催者・団体 |
| 場所 | 開催場所（オンライン含む） |
| 頻度 | 月1回、不定期など |
| 参加者 | 対象者、参加人数 |
| 内容 | テーマ、形式 |
| 参加費 | 無料/有料 |
| 参加方法 | 申込方法、会員限定か |
