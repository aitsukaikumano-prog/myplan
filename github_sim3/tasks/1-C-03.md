Anthropic Coworkの活用方法を研究・検証し、地域の人にAIの価値を体感してもらうためのデモ材料を構築する。

### 子タスク
1. **1-C-03-1**: Cowork最新情報の収集・まとめ

3. **1-C-03-3**: 検証結果のまとめ・デモ資料化

### この活動の戦略的意味
- Coworkは「非エンジニアでもAIエージェントが使える」ツール → 地域の人への説明に最適
- 検証結果は1-B-01-2-1（町民会館スタッフへのデモ）の材料になる
