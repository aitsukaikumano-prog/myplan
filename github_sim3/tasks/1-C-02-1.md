## 詳細説明

矢野町内混成ソフトバレーボール大会の得点管理をデジタル化するWebアプリを開発。
知り合いの大会運営手伝いをきっかけに、自発的に提案・1日で開発した。

### 大会情報
- **大会名**: 矢野町内混成ソフトバレーボール大会
- **主催**: 矢野町体育協会
- **開催日**: 2026-02-15
- **会場**: 矢野小学校体育館
- **規模**: 約50名・9チーム
  - グループA: 4チーム（3セット制）
  - グループB: 5チーム（2セット制）

### 経緯
1. 知り合いが大会運営の役回りに → 対戦表作成を手伝い始める
2. 「スマホで読み取れたらもっと便利じゃない？」とアプリを提案
3. イメージを作って見せる → 採用決定
4. AIを活用し1日で開発完了

### 従来の課題（ビフォー）
- スコアは紙で手書き管理、計算・集計は全部手作業
- 順位を知りたければ体育館端の張り紙を見に行くしかない
- 集計ミスや反映の遅れ

### アプリの機能（アフター）
- **QRコードアクセス**: 会場掲示のQRを読み取るだけ。インストール不要
- **リアルタイムスコア反映**: 入力した瞬間に全員のスマホに反映（Firebase同期）
- **自動集計**: 勝ち点・総得点・総失点・得失点差・順位を自動計算
- **管理者/閲覧モード**: URL分離で誤操作防止。管理者2名がスコア入力
- **3つの表示**: 対戦カード・順位表・対戦表マトリクス
- **グループ切替**: A/Bをワンタップで切替
- **スマホ対応**: コートサイドでも応援席でもどこからでも確認可能

### 使用技術・ツール
- **Google AI Studio** — アイデア整理・設計の壁打ち
- **Claude Code** — UIや機能の実装
- **Firebase** — リアルタイムデータ同期（Firestore）
- **React + TypeScript + Vite** — フロントエンド
