## 詳細説明

Coworkの最新情報を公式情報・技術記事・活用事例から収集し、整理する。

### 情報源
- **公式**: Anthropic公式サイト、Claude Help Center、公式ウェビナー
- **技術記事**: zenn.dev、note.com の日本語記事
- **海外記事**: TechCrunch、The New Stack等

### 収集すべき情報
1. **基本機能**: ファイル操作、フォルダ整理、文書作成、データ抽出
2. **プラグイン**: 11種の公式プラグイン（Productivity、Sales、Marketing、Finance、Legal、Customer Support等）
3. **Skills & Commands**: カスタムワークフローの作り方
4. **利用条件**: Pro($20/月)以上で利用可能、macOS必須、トークン消費量の目安
5. **活用事例**: フォルダ整理、メール一括処理、名刺データ化、議事録作成等
6. **町民会館向け活用候補**: 予約管理の整理、問い合わせ対応テンプレ、チラシ作成等
