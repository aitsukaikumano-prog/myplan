## 詳細説明

熊野町および周辺地域の産業支援機関をリストアップし、
AIコミュニティ活動との連携可能性を調査する。

### 目的

- AIコミュニティの活動を支援してくれる機関を見つける
- 補助金・助成金などの支援制度を把握する
- 既存のネットワークを活用するための情報収集

### 作業内容

1. 熊野町商工会の詳細情報を収集
2. 広島県の産業支援機関を調査
3. 安芸郡・近隣市の支援機関を調査
4. 各機関の支援内容・対象を整理
5. 連携可能性を評価してリスト化

## 調査項目

| 項目 | 内容 |
|------|------|
| 機関名 | 正式名称 |
| 所在地 | 住所・アクセス |
| 連絡先 | TEL・メール・担当部署 |
| 支援内容 | 経営相談、補助金、セミナー等 |
| 対象者 | 会員限定か、誰でもOKか |
| AI関連 | デジタル化・IT支援の有無 |
| 連携可能性 | 高/中/低 |

## メモ

- 商工会は1-B-01-2のヒアリング対象でもある
- 支援機関との連携は、勉強会の会場確保や広報に有効
- 補助金情報は、参加者へのメリット提供にも使える
