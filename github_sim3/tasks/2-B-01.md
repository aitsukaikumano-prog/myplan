## 詳細説明

継続的に学び合う定期勉強会を確立する。
「AI芸術系」と「AI効率化系」の2本柱を交互にテーマにして開催する。

### 目的

- 参加者が継続的にAIを学べる場を作る
- 2本柱でさまざまな層にアプローチする
- コミュニティの結束を強める

### 作業内容

1. 勉強会のフォーマットを設計
2. 年間テーマ計画を作成
3. 第1回勉強会を開催
4. 振り返り・改善
5. 月1回の定期開催を軌道に乗せる

### 子タスク

1. **2-B-01-1**: 勉強会フォーマット設計
2. **2-B-01-2**: 第1回勉強会開催
3. **2-B-01-3**: 月1回の定期開催体制確立

---

## 2本柱のテーマ設計

勉強会は「芸術系」と「効率化系」を交互に開催する。

### AI芸術系のテーマ例

| 回 | テーマ | 内容 |
|----|--------|------|
| 1 | AI画像生成入門 | Midjourney/DALL-Eで絵を作る |
| 2 | AI×書道 | AIで書体を変換、筆で再現 |
| 3 | AI動画作成 | 写真から動画を生成 |
| 4 | AIで絵手紙 | AI下絵→熊野筆で仕上げ |

### AI効率化系のテーマ例

| 回 | テーマ | 内容 |
|----|--------|------|
| 1 | ChatGPT入門 | 基本的な使い方、プロンプト |
| 2 | 文章作成効率化 | メール、報告書、提案書 |
| 3 | 情報整理・要約 | 長文の要約、議事録作成 |
| 4 | 業務自動化 | 定型作業の効率化 |

### 年間スケジュール案

| 月 | テーマ | 柱 |
|----|--------|-----|
| 1月 | ChatGPT入門 | 効率化 |
| 2月 | AI画像生成入門 | 芸術 |
| 3月 | 文章作成効率化 | 効率化 |
| 4月 | AI×書道 | 芸術 |
| 5月 | 情報整理・要約 | 効率化 |
| 6月 | AI動画作成 | 芸術 |
| ... | ... | ... |

## 勉強会フォーマット案

### 基本情報

| 項目 | 内容 |
|------|------|
| 頻度 | 月1回 |
| 曜日 | 土曜日午後（案） |
| 時間 | 2時間 |
| 場所 | 熊野町公民館 or 商工会 |
| 参加費 | 無料 or ワンコイン（500円） |

### プログラム構成（2時間）

| 時間 | 内容 |
|------|------|
| 0:00-0:10 | オープニング・前回振り返り |
| 0:10-0:30 | 今日のテーマ説明 |
| 0:30-1:20 | **ハンズオン/ワークショップ** |
| 1:20-1:40 | 成果共有・発表 |
| 1:40-2:00 | 質疑応答・次回案内・交流 |

---

## 継続のための工夫

| 工夫 | 理由 |
|------|------|
| 毎月同じ曜日・時間 | 予定を立てやすい |
| LINEグループで連絡 | 気軽にリマインド |
| 参加者の発表機会 | 自分ごと化、達成感 |
| 初心者歓迎の雰囲気 | 敷居を下げる |
| お菓子・飲み物 | 交流促進 |

---

## メモ

- 最初の数回は少人数でもOK、継続が大事
- 「芸術系」は親子参加もあり
- 「効率化系」は事業者向け、平日夜も検討
- 参加者のリクエストを聞いてテーマを調整
