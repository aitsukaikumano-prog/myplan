## 詳細説明

地域イベントのIT化・デジタル化を支援し、「AIやITで地域に貢献できる人」としての認知を広げる。

### 子タスク
1. **1-C-02-1**: ソフトバレー大会 得点表デジタル化
2. **1-C-02-2**: 成果の記録・ポートフォリオ化

### この活動の戦略的意味
- 事業者だけでなく**地域コミュニティ**への貢献実績になる
- 多くの住民の目に触れるため**認知度向上**に直結する
- 「ITの人」として地域に覚えてもらえる
