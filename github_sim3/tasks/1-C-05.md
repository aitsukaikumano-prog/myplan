## 詳細説明

AIヘアスタイルシミュレーションアプリの開発・公開、および海田町の美容院への導入。

### コンセプト
- 髪を切るのは失敗すると戻せない
- 事前に好きな髪型で似合うかどうかをAIでチェックできる
- 「なりたい自分になること」を後押しする

### 仕組み
1. ユーザーが自分の写真をアップロード
2. 好みの髪型を選択
3. AIが画像を加工し、その髪型にした場合のイメージを生成

### 導入先
- 海田町（熊野町隣町）の行きつけの美容院
- 実際に美容院で使ってもらっている
- 店舗にQRコード広告を設置
