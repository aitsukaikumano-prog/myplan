# Webアプリ開発経験の整理

## 概要

5つのWebアプリケーションを開発。ノーコード/ローコードツール（Dify, n8n）からフルスタック開発（React, Firebase）まで幅広く対応。特にAI/LLMを活用した業務効率化ツールの構築に強みを持つ。

## 開発プロジェクト一覧

### 1. ゴミ分別LINEbot（Dify）
- **概要**: 熊野町向けのゴミ分別案内チャットボット
- **技術的特徴**: RAG + コード照合のハイブリッド設計で表記揺れに対応
- **価値**: 住民からの問い合わせ対応を自動化

### 2. LINEブリッジ（n8n）
- **概要**: 異なるシステム間をLINEで連携するワークフロー
- **技術的特徴**: n8nによるノーコード自動化
- **価値**: 手動で行っていた情報転記を自動化

### 3. 髪型生成アプリ（NanoBanana+AI）
- **概要**: AIで髪型シミュレーションができるWebアプリ
- **技術的特徴**: Firebase + Stripe による課金システム込みの本番運用
- **価値**: 現在公開中。収益化の仕組みも構築済み

### 4. OCRアプリ（Dify）
- **概要**: 画像からテキストを抽出するツール
- **技術的特徴**: Difyによるワークフロー構築
- **価値**: 紙資料のデジタル化を支援

### 5. 業務ワークスペース（React+GitHub+Claude）
- **概要**: AIと連携した業務管理ツール
- **技術的特徴**: React + Vite + TypeScript、GitHub連携
- **着想**: マツダでの業務経験から課題を発見し開発
- **価値**: 目標管理と進捗の可視化を実現

## 技術スタック

| カテゴリ | 技術 |
|---------|------|
| フロントエンド | React, Vite, TypeScript |
| バックエンド | Firebase (Authentication, Firestore, Functions) |
| AI/ML | Dify (10本のフロー), n8n (3本のワークフロー), Claude |
| API連携 | LINE Messaging API, Stripe, OpenAI API |
| インフラ | GitHub, GitHub Actions |

## 強み

### 1. RAG + コード照合のハイブリッド設計
- 単純なRAGでは対応できない「表記揺れ」問題を解決
- ユーザーの曖昧な入力を正確な検索クエリに変換
- **製造業応用**: 部品検索、マニュアル検索で同様の課題を解決可能

### 2. AI駆動の業務環境構築
- AIをツールとしてではなく、業務フローの中心に据える設計
- 目標設定から進捗管理までをAIがサポート
- **製造業応用**: 目標管理、進捗可視化、レポート自動生成に展開可能

### 3. 本番運用経験
- 課金システム（Stripe）を含むサービスを公開・運用中
- 単なるプロトタイプではなく、実ユーザーが使えるレベルの品質

## 製造業への応用可能性

| 課題 | 解決アプローチ |
|------|---------------|
| 部品名の表記揺れで検索が困難 | RAGハイブリッド設計で曖昧検索を実現 |
| マニュアルが膨大で必要情報が見つからない | AI検索 + 要約で即座に回答 |
| 目標が曖昧で進捗が見えない | AI駆動の目標管理ツールで可視化 |
| 定型レポート作成に時間がかかる | テンプレート + AI生成で自動化 |
