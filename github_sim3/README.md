# マツダ救済プロジェクト

> マツダからAIコンサル案件を獲得するためのロードマップ

## 概要

このプロジェクトは、マツダに対してAIコンサルタントとして参画し、マツダの経営・業務改善を支援するための戦略的ロードマップです。

## 戦略構造

```
マツダからAIコンサル案件を獲得する
├── 1. 提案準備
├── 2. アプローチ・関係構築
└── 3. 案件獲得・実行
```

## 関連ファイル

- `STRATEGY.md` - 戦略の詳細定義
- `issues.yaml` - タスク一覧
- `output/` - 成果物保存
- `docs/` - 関連ドキュメント
