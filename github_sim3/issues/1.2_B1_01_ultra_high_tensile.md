# Issue #1.2-B1-01: 超高張力鋼板の適用拡大評価

## 1. 背景 (Context)
車体軽量化のため、1.5GPa級超高張力鋼板の適用部位を拡大し、剛性を維持しながら車体重量を50kg削減することを目指す。

## 2. 具体的タスク (Tasks)
- [ ] 現行車体の部位別重量・強度マップ作成
- [ ] 超高張力鋼板適用候補部位の選定（CAE解析）
- [ ] ホットスタンプ成形条件の最適化
- [ ] 衝突安全性能シミュレーション

## 3. 成功の定義 (Definition of Done)
- 車体重量50kg削減の設計案が完成していること
- 衝突安全性能が現行同等以上であること
