# Issue #1.3-C1-01: アクティブエアロシステムの効果検証

## 1. 背景 (Context)
高速走行時の空気抵抗を低減するため、可変式エアロパーツ（アクティブグリルシャッター、リトラクタブルスポイラー）の効果を検証し、燃費向上と冷却性能のバランスを最適化する。

## 2. 具体的タスク (Tasks)
- [ ] 風洞試験によるCd値測定（シャッター開閉時）
- [ ] エンジン冷却水温と空力デバイスの制御ロジック策定
- [ ] 実走行モードでの燃費改善効果測定
- [ ] コスト対効果分析（投資回収期間算出）

## 3. 成功の定義 (Definition of Done)
- 高速燃費（100km/h定常）で5%以上改善すること
- 冷却性能に悪影響がないこと
