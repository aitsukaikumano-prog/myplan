# Issue #1.2-B2-01: マルチマテリアル接合技術の量産検証

## 1. 背景 (Context)
アルミニウムと鋼板の異種材接合技術を確立し、適材適所の材料配置による軽量化と生産性の両立を図る。

## 2. 具体的タスク (Tasks)
- [ ] FSW（摩擦撹拌接合）の接合強度評価
- [ ] SPR（セルフピアスリベット）の量産ライン適用検討
- [ ] 電食防止コーティングの耐久性試験
- [ ] 接合部の品質検査手法の確立

## 3. 成功の定義 (Definition of Done)
- 接合強度が溶接同等以上であること
- 量産タクトタイム内での接合が可能であること
