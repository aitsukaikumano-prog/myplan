# Issue #1.1-A2-01: フリクション低減オイル適合性評価

## 1. 背景 (Context)
エンジン内部のフリクションロスを低減するため、低粘度オイル（0W-8相当）の適用可能性を評価し、耐久性とのバランスを検証する。

## 2. 具体的タスク (Tasks)
- [ ] 現行オイル仕様でのフリクション損失の詳細測定
- [ ] 低粘度オイル候補3種の摩耗試験実施
- [ ] 高温・高負荷条件での油膜厚さシミュレーション
- [ ] 10万km相当耐久試験計画の策定

## 3. 成功の定義 (Definition of Done)
- フリクション損失が現行比15%低減すること
- 10万km耐久試験で異常摩耗がないこと
