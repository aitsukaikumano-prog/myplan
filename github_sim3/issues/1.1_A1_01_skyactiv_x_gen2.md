# Issue #1.1-A1-01: SKYACTIV-X Gen2 圧縮着火制御の最適化

## 1. 背景 (Context)
SKYACTIV-X第2世代エンジンにおいて、SPCCI（火花点火制御圧縮着火）の制御精度をさらに向上させ、より広い運転領域で圧縮着火を実現することで燃費性能を10%以上改善する。

## 2. 具体的タスク (Tasks)
- [ ] 現行Gen1エンジンの圧縮着火成功率マップの作成
- [ ] 点火時期・燃料噴射タイミングの最適化シミュレーション
- [ ] 冷間始動時の圧縮着火安定性テスト
- [ ] EGR率と圧縮着火率の相関分析

## 3. 成功の定義 (Definition of Done)
- 圧縮着火適用領域が現行比30%拡大していること
- WLTC燃費で10%以上の改善が確認できること
