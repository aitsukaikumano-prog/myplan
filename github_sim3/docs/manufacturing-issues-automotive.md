# 自動車製造業の課題リサーチ結果

最終更新: 2026-01-14

## 概要

自動車製造業特有の課題を整理し、特に中堅OEM（マツダ等）やTier1サプライヤーが直面する構造的問題を分析した。

---

## 1. 自動車業界特有の構造的課題

### 1.1 CASE対応

| 要素 | 課題 | 中堅OEMへの影響 |
|------|------|-----------------|
| **C**onnected | 車載ソフトウェア開発力の不足 | 外注依存によるデジタル赤字リスク（2035年に最大1.3兆円） |
| **A**utonomous | 自動運転技術への巨額投資 | 開発リソース不足で遅れ |
| **S**hared | カーシェア・MaaS対応 | 販売台数減少リスク |
| **E**lectric | EV開発・バッテリー投資 | 投資規模が経営を圧迫 |

### 1.2 サプライチェーンの複雑性

| 課題 | 詳細 |
|------|------|
| 多層構造 | 国内自動車10社のサプライチェーン企業数: 68,338社 |
| 小規模企業依存 | 76.4%が売上10億円未満、Tier階層が下がるほど小規模 |
| 価格転嫁困難 | 下位Tierほど受け身の価格設定、コスト上昇分を吸収 |
| 営業赤字率 | Tier1: 24%、Tier2: 32%、Tier3以降: 35%（2024年） |

### 1.3 品質要求水準

| 課題 | 詳細 |
|------|------|
| リコールリスク | 品質問題による大規模リコールの経営インパクト |
| トレーサビリティ | 部品単位での履歴追跡が必須 |
| 認証対応 | IATF16949等の品質規格への準拠 |

---

## 2. バリューチェーン別課題（自動車特化）

### 2.1 開発

| 課題 | 詳細 | マツダへの示唆 |
|------|------|---------------|
| モデルサイクル短縮 | EV化で開発スピード競争激化 | 「意志あるフォロワー」戦略で過剰投資回避 |
| プラットフォーム戦略 | 共通化によるコスト削減 | トヨタ・スバルとの3社連携 |
| ソフトウェア人材 | CASE実現にはSW人材が必須 | 外部との協業が必要 |
| SDV対応 | 車両のソフトウェア定義化 | 2040年に車載SW売上が40%に達する見込み |

### 2.2 調達

| 課題 | 詳細 |
|------|------|
| Tier構造の再編 | EVシフトでエンジン系部品が不要に、モーター・バッテリー系が重要に |
| バッテリー原材料 | リチウム・コバルト・ニッケルの調達リスク（地政学的制約） |
| 部品共通化 | 電動化投資を抑えるための共同調達 |
| 半導体不足 | 現代の自動車は電子部品に依存、調達困難が生産を阻害 |

### 2.3 生産

| 課題 | 詳細 |
|------|------|
| 混流生産 | EV/HV/ICE車の並行生産による複雑性 |
| ライン最適化 | 生産設備の柔軟な転換 |
| 予知保全 | AIやIoTを活用した生産ラインの予知保全 |
| 5G活用 | リアルタイム監視による工場全体の状況把握 |

### 2.4 品質

| 課題 | 詳細 |
|------|------|
| リコール対応 | 迅速な原因特定と対策実施 |
| トレーサビリティ | 部品履歴の追跡システム整備 |
| AI検査 | 画像認識による自動検査導入 |

## 3. 中堅OEM特有の課題

### 3.1 開発リソースの制約

| 指標 | マツダ | トヨタ | 課題 |
|------|--------|--------|------|
| 年間販売台数 | 約120万台 | 約1,000万台 | 規模の差が投資余力に直結 |
| 電動化投資 | 1.5兆円（当初計画） | - | インフレで2兆円に膨張→見直しで圧縮 |
| 開発人員 | 限定的 | 豊富 | ソフトウェア人材の確保が困難 |

### 3.2 スケールメリット不足

| 課題 | 詳細 | 対応策 |
|------|------|--------|
| 部品調達コスト | 大量発注できず単価高 | 長安汽車との共同開発EVで電池調達量を圧縮 |
| 設備投資効率 | 生産台数が少なく償却負担大 | 「ライトアセット戦略」で投資最小化 |
| 技術開発 | 全方位開発は不可能 | トヨタ・スバルとの3社連携 |

### 3.3 電動化投資負担

| 企業 | 電動化投資計画 | 課題 |
|------|---------------|------|
| マツダ | 1.5兆円（2030年まで） | 投資内容見直しで圧縮、EVは「意志あるフォロワー」 |
| スバル | 1.5兆円（2030年まで） | EV計画後ろ倒しの可能性、HVへの投資強化 |
| 日産 | - | 収益悪化で投資余力低下 |

### 3.4 「稼ぐ手段」の不在

| 企業 | 収益源 | 課題 |
|------|--------|------|
| トヨタ | HVで世界規模の収益 | - |
| ホンダ | 東南アジア2輪 | - |
| マツダ・スバル | 特化した収益源なし | エンジン車減少と巨額投資の荒波に直面 |

## 4. Tier1サプライヤーの課題

### 4.1 事業構造転換

| 課題 | 詳細 |
|------|------|
| エンジン部品不要化 | EV化でエンジン・トランスミッション需要消滅 |
| 新規事業開発 | モーター・バッテリー関連への転換 |
| 投資判断 | OEMより経営基盤が弱く、判断がより困難 |

### 4.2 DX/AI活用の現状

| 領域 | 動向 |
|------|------|
| 予知保全 | AIやIoTを組み込んだロボットシステムで強化中 |
| 品質管理 | AI画像認識による自動検査 |
| 自動運転開発 | TURING、TIER IV、Denso等がAI技術開発を推進 |
| NPU開発 | DensoとQuadricがAI用半導体を共同開発（2024年11月発表） |

### 4.3 データプラットフォームの課題

| 課題 | 詳細 |
|------|------|
| 海外クラウド依存 | Tier1-Tier2間のデータ連携はAWS一択の状況 |
| ノウハウ流出リスク | 製造ノウハウや設計データが海外PFに蓄積 |
| デジタル赤字 | 車載ソフトウェアを外国企業に依存すると2035年に最大1.3兆円の赤字 |

## 5. 外部環境の影響

### 5.1 規制動向

| 地域 | 動向 |
|------|------|
| 欧州 | EV販売減速、バッテリー投資縮小（8社が延期・断念） |
| 米国 | 25%追加関税（2025年5月〜）、EV推進取りやめ |
| 中国 | EV市場牽引役（2024年: 1,130万台、前年比40%増） |
| 日本 | マルチパスウェイ戦略（EV/HV/FCV等の多様な選択肢） |

### 5.2 市場動向

| 指標 | 2024年実績 |
|------|------------|
| 世界EV販売台数 | 1,750万台（前年比25%増） |
| 中国EV販売 | 1,130万台（前年比40%増） |
| 欧州EV販売 | 318万台（ほぼ横ばい） |
| 米国EV販売 | 152万台（約10%増） |

### 5.3 消費者行動の変化

| 変化 | 影響 |
|------|------|
| 若者の車離れ | 都市部で公共交通優先、維持費負担から所有に消極的 |
| カーシェア普及 | 個人所有からシェアリングへのシフト |
| 整備士不足 | 有効求人倍率上昇、整備学校入学者15年で半減 |

## 6. マツダへの示唆

### 6.1 強み活用の方向性

| 強み | 活用方向 |
|------|----------|
| 内燃機関技術 | カーボンニュートラル燃料対応エンジン |
| 少量多品種生産 | 柔軟な生産体制を活かした差別化 |
| デザイン・ブランド | プレミアム路線での価値訴求 |

### 6.2 連携強化の必要性

| 連携先 | 期待効果 |
|--------|----------|
| トヨタ・スバル | エンジン共同開発、プラットフォーム共有 |
| 中国・長安汽車 | EV共同開発による投資圧縮 |
| Tier1サプライヤー | DX/AI活用による生産効率化 |

### 6.3 AI/DXによる競争力強化

| 領域 | 施策 |
|------|------|
| 生産 | 予知保全、AI品質検査 |
| 開発 | デジタルツイン活用 |
| SCM | AIによる需給最適化 |
| 技能継承 | ノウハウのデジタル化 |
