- スタッフから「地域住民向けにAI講座をやってみないか」と提案を受けた
- 2月末に再度訪問し、企画書をベースに打ち合わせ予定
- 早くて4月スタート

## スタッフとの会話メモ（2/12）

### 講座への期待
- AI生成講座は集まると思う
- AIに触れてみたいというニーズは多い、後押ししてあげたい
- 実務で使えること（チラシのデザインを考えるなど）も望まれている
- 成果物があった方がいい — 達成感が出る、やった感がある
- 口コミ効果：持って帰った人が宣伝してくれる
- 言葉だけではなくて「こういうのもできるよ」という感じ

### 運営面
- PCは持参してもらう。スマホでもいいかも知れない
- 操作は先生の画面を投影しながら一緒に進める感じ
- ターゲットは絞ってやった方がいい
- 個人のレベルが違いすぎると進行が難しい
- 条件をつけて募集した方がいい（キーボードが打てる人、興味がある人など）
- 初級・中級・上級を分けた方がいい

### ターゲット層
- 40-50代 → 夜、土日の方がいい
- 70-80代が多い → 優しく入門でもいい
- 画像系は重くなるので、文字でサクサクできる方がいい

### AIリスクについて
- デメリットもしっかり教えて欲しい
- AIの言うことを鵜呑みにしない
- AIに支配される、ということも教えて欲しい

### 最終的なビジョン
- 本当は何かやりたい熱のある人たちが集まって、先生を呼んで、継続的なイベントとして開催できる「社会教育グループ」みたいなのが一番
- → これは私（大輝）のコミュニティ構築目標と完全に一致

### 別件：レジン講座
- レジン作りの経験があり、レジン講師も要望された
- 子供向け、親子向けなどでもOK
- 単発。夏休みの工作的なものでもいい
- 100円ショップで揃うようなものをこちらで準備
- → AI講座とは別企画として分離

## 企画の方針（Claude Codeとの検討結果）

### 基本戦略
- **第1弾は「体験会」1回**で小さく始める
- いきなり全レベル連続講座ではなく、まず成功体験を作る
- 成功すれば「次もやってほしい」と自然につながる
- 企画書には「第1弾：体験会」を具体的に、「今後の展開案」は付録で軽く添える

### 2案並行で企画書を作成
- **案A（40-50代向け）** と **案B（70-80代向け）** を両方作る
- 打ち合わせで両方見せて、スタッフと相談して決める

### 各案の設計

| 項目 | 案A: 40-50代 | 案B: 70-80代 |
|------|-------------|-------------|
| 時間帯 | 夜 or 土日 | 日中 |
| 端末 | PC or スマホ | スマホ中心 |
| ツール | ChatGPT（テキストベース） | ChatGPT（テキストベース） |
| 形式 | 講師画面を投影、一緒に進める | 同左（よりゆっくり） |
| 定員 | 10名 | 10名 |
| 募集条件 | キーボード入力ができる方 | スマホで文字入力ができる方 |
| 成果物候補 | チラシ文案、ビジネス文書 | 手紙、俳句、レシピ |
| 所要時間 | 90分（テンポよく） | 90分（セットアップに余裕） |
| 参加動機 | 仕事・実用性 | 好奇心・生活の便利さ |

### 共通で含めること
- AIリスクの説明（鵜呑みにしない、個人情報を入れない等）
- 印刷して持ち帰れる成果物
- アンケート（次回ニーズの把握）
- 今後の展開ビジョン（社会教育グループへの発展）
