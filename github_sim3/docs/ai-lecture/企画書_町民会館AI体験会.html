1. KUMANO AI STUDIOについて

「暮らしている人が、人間として幸せを感じる社会を作る」

AIで何もかもを効率化した無機質な社会ではなく、人と会って話をして、何かを一緒に作って楽しむ——そういう暮らしを目指しています。

AIはそのための道具です。AIを使えば、自分の中にある考えや想いを文章や絵にしやすくなる。AIで仕事を楽にすれば、人と過ごす時間や何かを作る時間が生まれる。KUMANO AI STUDIOは、「自分を表現する方法」と「仕事を楽にする方法」、そして「人と一緒に楽しむ場」を提供する活動です。

なぜ町民会館で講座をやりたいのか

町民会館は、地域の方が集まり、学び、つながる場所です。私たちは講座を通じて、以下のような流れを作りたいと考えています：

1まずAIに触れてみる（体験会）→ 「面白い！自分にもできる！」
▼
2AIで何かを作ってみる（絵、名刺、データ処理ツールなど）→ 「自分のやりたいことが形になった！」
▼
3仲間と一緒に継続的に活動する（コミュニティ化）→ 居場所ができる

最初は小さな体験会から始めて、参加者の声を聞きながら段階的に育てていきます。ゆくゆくは、参加者同士が教え合い、やりたいことに挑戦し合える社会教育グループに発展させたいと考えています。

2. 企画の背景

  • 「AIに触れてみたい」という地域住民のニーズが高まっている
  • 一方で、何から始めればいいかわからない人が大半
  • 町民会館が地域の学びの場として、AIの「最初の一歩」を提供する意義は大きい

4. 今回の企画 — まずは入門の体験会から

この体系の最初の一歩として、まずは入門の体験会を実施したいと考えています。

  1. 地域住民がAIを実際に触って「自分にもできる」と感じる体験を提供する
  2. AIの便利さだけでなく、リスク・注意点も正しく伝える
  3. 成果物を持ち帰ってもらうことで達成感と口コミ効果を生む
  4. 参加者の反応を見て、今後の継続的な講座の可能性を探る
案A: はたらく世代向け「AIで仕事の文章を作ってみよう」

アカウント作成パート（0:20〜0:50）の進め方

シニアの方にとって最大のハードル。全員が確実にできるよう、丁寧に進めます。

ステップ内容時間ポイント
①ChatGPTアプリをインストール5分App Store / Google Playの開き方から案内。画面を投影しながら
②アプリを開いて「登録」をタップ3分「サインアップ」ではなく画面上のボタンの色・位置で案内
③メールアドレスを入力7分メールアドレスがわからない方→Gmailの確認方法も案内
④届いたメールの確認コードを入力5分「メールを開いてください」→迷惑メールフォルダの確認も
⑤名前・生年月日を入力5分本名でなくてもOKと伝える
⑥完了！最初の画面が出たら拍手5分全員ができたことを確認。できた人は隣の人を手伝う

想定トラブルと対策

  • メールアドレスを忘れた → スマホの「設定」から確認する手順を案内
  • パスワードが入力できない → 音声入力やサポート役が代行
  • 確認コードが届かない → 迷惑メールフォルダ確認、再送信ボタンの案内
  • そもそもメールアドレスがない → 事前案内で「メールアドレスが必要」と伝えておく

実践ワークの例

  • 友人への近況報告の手紙
  • お世話になった方へのお礼の手紙
  • 季節のあいさつ文（暑中見舞い、年賀状の文面など）
  • 孫への誕生日メッセージ
  • 旅行の計画を相談してみる

参加者の心理設計

タイミング参加者の気持ち講師の対応
開始前「機械は苦手なんだけど…」「スマホで話しかけるだけです」と伝える
AI説明「テレビで見たことある」身近な例（天気予報、カーナビ）で説明
アカウント作成「画面がわからない…」サポート役と一緒に1人ずつ確認。焦らせない
作成完了「できた！」全員で拍手。「これで自分のAIができました」
休憩中ほっとする / まだ不安個別フォロー。できた人同士で雑談を促す
初めての会話「あら、ちゃんと答えてくれる！」驚きと笑いを共有する
手紙ワーク「これは便利ね」「自分の言葉で直してもいいですよ」と伝える
印刷物受け取り「うちに帰って見せよう」「ぜひご家族に見せてください」

シニア向け特別な配慮

  • 音声入力を積極的に案内: 文字入力が苦手な方でも参加できる
  • サポート役を必ず配置: 最低2名、理想は3名（アカウント作成時に1対3程度でフォロー）
  • 画面は大きく投影: 「ここを押してください」が見える大きさで
  • 進行はゆっくり: 全員がついてこられることを最優先
  • 専門用語を使わない: 「ログイン」→「入る」、「アカウント」→「自分の名前の登録」
  • 休憩を必ず入れる: 2時間は長いので、中間で10分休憩

5. AIのリスク・注意点について（両案共通）

講座の中で必ず以下を伝えます：

リスク伝え方
AIは間違えることがある「AIは賢いアシスタントだが、たまに嘘をつく。必ず自分で確認を」
個人情報を入れない「名前、住所、電話番号は絶対に入力しないでください」
著作権への配慮「AIが作った文章をそのまま公式な場で使うときは注意が必要」
AIに依存しすぎない「考えることをやめない。AIはあくまで道具です」

8. 今後の展開ビジョン

1AI体験会（今回の企画）→ まずAIに触れてみる。「面白い！」を体験する
▼
2名刺作り講座 → 「自分は何をしたい人か」を考え、AIで名刺を作る。自分を表現する第一歩
▼
3テーマ別ワークショップ（チラシ作り、画像生成など）→ 表現の幅を広げる。実用的な成果物も作れる
▼
4社会教育グループとして定期開催 → 参加者同士が教え合い、やりたいことに挑戦する居場所へ

最初から大きくせず、参加者の声を聞きながら段階的に育てていく方針です。体験が先、気づきは後から自然についてくる — この順番を大切にします。
