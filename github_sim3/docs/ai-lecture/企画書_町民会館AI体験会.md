## 1. KUMANO AI STUDIOについて

### ビジョン
**「暮らしている人が幸せを感じる地域を作る」**

私たちが目指しているのは、AIで何もかもを効率化した無機質な社会ではありません。

人の幸せは、人と人とが実際に会って、話をして、何か楽しいことを一緒にやることの中にあると考えています。生きた人間同士の継続的なコミュニケーション — それが「居場所」になります。

AIはそのための道具です。AIを使えば、自分の考えを形にしたり、新しい表現方法を見つけたり、これまでできなかったことに挑戦できるようになります。

KUMANO AI STUDIOは、**AIを通じて「自分を表現する方法」と「表現する場所」の両方を提供する**活動です。

### 活動の2本柱

| 柱 | 内容 | 目指すこと |
|---|---|---|
| **AIアート** | AIを使った作品制作・発信 | 一人一人がAIで自分を表現し、やりがいを感じる |
| **AI活用支援** | 地域の困りごとをAIで解決 | 仕事や生活がもっと楽に、もっと面白くなる |

どちらの柱も、最終的には**人と人とのつながりの場を作る**ことにつながっています。

### これまでの実績
- **AIヘアスタイルシミュレーションアプリ** — 開発し、海田町の美容院に実際に導入
- **ソフトバレー大会 得点表デジタル化** — 地域イベントのIT支援
- **熊野町AIアート** — 熊野町の風景をAIで加工した作品を20点以上制作・公開中
- **Cowork検証会**（2/12 町民会館） — AIツールの活用方法を実際にデモ
- **生成AI-LT広島vol.2 登壇**（2/18） — 広島のAIコミュニティで事例発表

### なぜ町民会館で講座をやりたいのか

町民会館は、地域の方が集まり、学び、つながる場所です。

私たちは講座を通じて、以下のような流れを作りたいと考えています：

```
① まずAIに触れてみる（体験会）
     → 「面白い！自分にもできる！」
② AIで何かを作ってみる（名刺作り、チラシ作りなど）
     → 「自分はこれを表現したかったんだ」
③ 仲間と一緒に継続的に活動する（コミュニティ化）
     → 居場所ができる
```

最初は小さな体験会から始めて、参加者の声を聞きながら段階的に育てていきます。ゆくゆくは、参加者同士が教え合い、やりたいことに挑戦し合える**社会教育グループ**に発展させたいと考えています。

費用はいただきません。地域貢献として取り組みます。

## 2. 企画の背景

- 「AIに触れてみたい」という地域住民のニーズが高まっている
- 一方で、何から始めればいいかわからない人が大半
- 町民会館が地域の学びの場として、AIの「最初の一歩」を提供する意義は大きい

## 3. 企画の目的

1. 地域住民が**AIを実際に触って「自分にもできる」と感じる**体験を提供する
2. AIの便利さだけでなく、**リスク・注意点も正しく伝える**
3. **成果物を持ち帰ってもらう**ことで達成感と口コミ効果を生む
4. 参加者の反応を見て、今後の継続的な講座の可能性を探る

## 案A: はたらく世代向け「AIで仕事の文章を作ってみよう」

### 基本情報

| 項目 | 内容 |
|------|------|
| 対象 | 40〜50代の方（仕事や日常でPCを使う方） |
| 日時 | 平日夜（19:00〜20:30）または 土日午後 |
| 定員 | 10名 |
| 持ち物 | ノートPC または スマートフォン |
| 参加条件 | キーボードまたはスマホで文字入力ができる方 |
| 費用 | 無料 |
| 使用ツール | ChatGPT（無料版） |

### 講座のゴール

**「自分の仕事に使える文章を、AIに1つ作ってもらう」**

参加者が持ち帰るもの：
- AIが作成した文章の印刷物（お礼メール、案内文、チラシ文案など）
- AI活用のコツをまとめたミニガイド（A4 1枚）

### タイムライン（90分）

| 時間 | 内容 | ねらい |
|------|------|--------|
| 0:00〜0:10 | オープニング・自己紹介 | 場の雰囲気づくり |
| 0:10〜0:20 | AIとは？（デモを見せながら説明） | 「こんなことができるのか！」と興味を引く |
| 0:20〜0:30 | ChatGPTにログイン・初めての質問 | 全員が動く状態にする |
| 0:30〜0:40 | 自由に質問してみよう | AIとのやりとりに慣れる |
| 0:40〜1:10 | 実践ワーク「仕事で使える文章を作ろう」 | 自分ごとにする、成果物を作る |
| 1:10〜1:20 | AIの注意点・リスク | 正しい使い方を伝える |
| 1:20〜1:30 | まとめ・アンケート・今後のご案内 | 次につなげる |

### 実践ワークの例（参加者が選べるように複数用意）

- お客様へのお礼メールを書いてもらう
- イベントの案内文を作ってもらう
- チラシのキャッチコピーを考えてもらう
- 会議の議事録をまとめてもらう
- 自分の仕事を説明すると、改善案を提案してもらえる

### 参加者の心理設計

| タイミング | 参加者の気持ち | 講師の対応 |
|-----------|--------------|-----------|
| 開始前 | 「ついていけるかな」 | 「今日はとにかく楽しむだけでOK」と伝える |
| デモ時 | 「すごい、でも難しそう」 | 簡単な例を見せて「これだけです」と安心させる |
| 初めての質問 | 「本当にできた！」 | 全員ができたことを確認、拍手 |
| 実践ワーク | 「自分の仕事でも使える！」 | 個別にサポート、うまくいった人を紹介 |
| リスク説明 | 「なるほど、気をつけよう」 | 怖がらせず、具体例で伝える |
| 終了後 | 「もっとやりたい」「次はいつ？」 | アンケートで次回ニーズを回収 |

## 案B: シニア向け「AIとおしゃべりしてみよう」

### 基本情報

| 項目 | 内容 |
|------|------|
| 対象 | 70〜80代の方（AIに興味がある方） |
| 日時 | 平日日中（10:00〜12:00 または 13:00〜15:00） |
| 定員 | 10名（サポート役2〜3名を配置） |
| 持ち物 | スマートフォン |
| 参加条件 | スマホで文字入力ができる方（音声入力でもOK） |
| 費用 | 無料 |
| 使用ツール | ChatGPT（無料版） |

### 講座のゴール

**「AIのアカウントを作り、AIに手紙を書いてもらって、印刷して持ち帰る」**

参加者が持ち帰るもの：
- AIが作成した手紙の印刷物（友人への近況報告、お礼状など）
- 「AIの使い方かんたんガイド」（大きい文字、A4 1枚）

### タイムライン（120分・休憩込み）

| 時間 | 内容 | ねらい |
|------|------|--------|
| 0:00〜0:10 | オープニング・自己紹介 | 緊張をほぐす。「今日はゆっくりやります」 |
| 0:10〜0:20 | AIとは？（身近な例で説明） | 「テレビで見たやつか！」と親しみを持つ |
| 0:20〜0:50 | **ChatGPTのアカウント作成**（全員一緒に進める） | 全員が「自分のAI」を持てる状態にする |
| 0:50〜1:00 | **休憩**（10分） | 疲れをとる。個別サポートの時間にも |
| 1:00〜1:10 | 最初のひとこと — AIに話しかけてみる | 「あら、ちゃんと答えてくれる！」 |
| 1:10〜1:20 | 自由にAIとおしゃべり | 「何を聞いてもいいんだ」と実感する |
| 1:20〜1:45 | 実践ワーク「AIに手紙を書いてもらおう」 | 成果物を作る |
| 1:45〜1:50 | AIの注意点 | わかりやすく、簡潔に |
| 1:50〜2:00 | まとめ・アンケート・今後のご案内 | 感想を聞く、次につなげる |

### アカウント作成パート（0:20〜0:50）の進め方

シニアの方にとって最大のハードルがここ。**全員が確実にできるよう、丁寧に進める。**

| ステップ | 内容 | 所要時間 | ポイント |
|---------|------|---------|---------|
| ① | ChatGPTアプリをインストール | 5分 | App Store / Google Playの開き方から案内。画面を投影しながら |
| ② | アプリを開いて「登録」をタップ | 3分 | 「サインアップ」ではなく画面上のボタンの色・位置で案内 |
| ③ | メールアドレスを入力 | 7分 | メールアドレスがわからない方→Gmailの確認方法も案内 |
| ④ | 届いたメールの確認コードを入力 | 5分 | 「メールを開いてください」→迷惑メールフォルダの確認も |
| ⑤ | 名前・生年月日を入力 | 5分 | 本名でなくてもOKと伝える |
| ⑥ | 完了！最初の画面が出たら拍手 | 5分 | 全員ができたことを確認。できた人は隣の人を手伝う |

**想定トラブルと対策：**
- メールアドレスを忘れた → スマホの「設定」から確認する手順を案内
- パスワードが入力できない → 音声入力やサポート役が代行
- 確認コードが届かない → 迷惑メールフォルダ確認、再送信ボタンの案内
- そもそもメールアドレスがない → 事前案内で「メールアドレスが必要」と伝えておく

### 実践ワークの例

- 友人への近況報告の手紙
- お世話になった方へのお礼の手紙
- 季節のあいさつ文（暑中見舞い、年賀状の文面など）
- 孫への誕生日メッセージ
- 旅行の計画を相談してみる

### 参加者の心理設計

| タイミング | 参加者の気持ち | 講師の対応 |
|-----------|--------------|-----------|
| 開始前 | 「機械は苦手なんだけど…」 | 「スマホで話しかけるだけです」と伝える |
| AI説明 | 「テレビで見たことある」 | 身近な例（天気予報、カーナビ）で説明 |
| アカウント作成 | 「画面がわからない…」 | サポート役と一緒に1人ずつ確認。焦らせない |
| 作成完了 | 「できた！」 | 全員で拍手。「これで自分のAIができました」 |
| 休憩中 | ほっとする / まだ不安 | 個別フォロー。できた人同士で雑談を促す |
| 初めての会話 | 「あら、ちゃんと答えてくれる！」 | 驚きと笑いを共有する |
| 手紙ワーク | 「これは便利ね」 | 「自分の言葉で直してもいいですよ」と伝える |
| 印刷物受け取り | 「うちに帰って見せよう」 | 「ぜひご家族に見せてください」 |

### シニア向け特別な配慮

- **音声入力を積極的に案内**: 文字入力が苦手な方でも参加できる
- **サポート役を必ず配置**: 最低2名、理想は3名（アカウント作成時に1対3程度でフォロー）
- **画面は大きく投影**: 「ここを押してください」が見える大きさで
- **進行はゆっくり**: 全員がついてこられることを最優先
- **専門用語を使わない**: 「ログイン」→「入る」、「アカウント」→「自分の名前の登録」
- **休憩を必ず入れる**: 2時間は長いので、中間で10分休憩。トイレ休憩も兼ねる

## 5. AIのリスク・注意点について（両案共通）

講座の中で必ず以下を伝えます：

| リスク | 伝え方 |
|--------|--------|
| AIは間違えることがある | 「AIは賢いアシスタントだが、たまに嘘をつく。必ず自分で確認を」 |
| 個人情報を入れない | 「名前、住所、電話番号は絶対に入力しないでください」 |
| 著作権への配慮 | 「AIが作った文章をそのまま公式な場で使うときは注意が必要」 |
| AIに依存しすぎない | 「考えることをやめない。AIはあくまで道具です」 |

## 8. 今後の展開ビジョン

```
第1弾: AI体験会（今回の企画）
  → まずAIに触れてみる。「面白い！」を体験する
  ↓
第2弾: 名刺作り講座
  → 「自分は何をしたい人か」を考え、AIで名刺を作る
  → 自分を表現する第一歩
  ↓
第3弾: テーマ別ワークショップ（チラシ作り、画像生成など）
  → 表現の幅を広げる。実用的な成果物も作れる
  ↓
将来: 社会教育グループとして定期開催
  → 参加者同士が教え合い、やりたいことに挑戦する居場所へ
```

最初から大きくせず、**参加者の声を聞きながら段階的に育てていく**方針です。
体験が先、気づきは後から自然についてくる — この順番を大切にします。
