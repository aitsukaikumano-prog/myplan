## サービス案1: 技能見える化パック

### 基本情報

| 項目 | 内容 |
|------|------|
| サービス名 | **技能見える化パック** |
| キャッチコピー | 「熟練の技、まず見えるようにしませんか」 |
| 価格 | **50-100万円**（税別） |
| 期間 | **1ヶ月** |

### 対象顧客

| 属性 | 詳細 |
|------|------|
| 企業規模 | 従業員50-200名の製造業 |
| DX成熟度 | 初期段階（まだ何もしていない） |
| 課題認識 | 「技能継承が大事なのは分かるが、何から始めればいいか分からない」 |
| 予算感 | 100万円以下で試したい |

### 顧客ペルソナ
> **広島県の金属加工業A社（従業員80名）**
> - 熟練の溶接工（58歳）があと3年で定年
> - 後継者育成が課題だが、何を教えればいいか言語化できていない
> - DXは「大企業のもの」と思っている
> - 「まず100万円以下で試してみたい」

### 解決する課題

1. 熟練者の技能が「暗黙知」のまま
2. 何を残すべきか分からない
3. DXの第一歩が踏み出せない

### 提供価値

| 提供するもの | 顧客が得る価値 |
|-------------|---------------|
| 作業動画の撮影・分析 | 熟練技能の可視化 |
| ポイント一覧の作成 | 教育項目の明確化 |
| 優先順位付け | 次のアクションが分かる |

### 成果物

1. **技能分析レポート**（PDF 20-30ページ）
   - 対象工程の概要
   - 熟練者の作業分析結果
   - 初心者との差分ポイント
   - 言語化された「コツ」一覧

2. **作業ポイント一覧**（Excel）
   - 工程ごとの重要ポイント
   - 習熟度チェック項目
   - 優先的にDB化すべき領域

### 作業プロセス

```
Week 1: ヒアリング・現場視察
  ↓
Week 2: 動画撮影（熟練者 + 若手）
  ↓
Week 3: 分析・ドキュメント化
  ↓
Week 4: 報告会・納品
```

### 実現可能性

| 要素 | 評価 | 根拠 |
|------|------|------|
| 技術的難易度 | ◎ 低い | 動画分析 + ドキュメント化のみ |
| 必要スキル | ◎ 保有 | ヒアリング・分析・文書化 |
| 外部依存 | ◎ なし | ツール不要、人力で完結 |

### 差別化ポイント

| 従来のアプローチ | 本サービス |
|-----------------|-----------|
| 「DX導入しましょう」（抽象的） | 「まず見えるようにしましょう」（具体的） |
| 高額なシステム導入前提 | 50万円から開始可能 |
| IT部門主導 | 現場主導で進められる |

### 収益モデル

- **初回**: 50-100万円（技能見える化パック）

### 基本情報

| 項目 | 内容 |
|------|------|
| サービス名 | **業務効率化ライトパック** |
| キャッチコピー | 「まず1つの業務から、自動化してみませんか」 |
| 価格 | **50-100万円**（税別） |
| 期間 | **2-4週間** |
| コンセプト | 1業務の自動化で効果を実感 |

### 対象顧客

| 属性 | 詳細 |
|------|------|
| 企業規模 | 従業員100-500名の製造業 |
| 課題 | 事務作業に追われて本来の仕事に集中できない |
| 現状 | Excel転記、メール対応、レポート作成など手作業が多い |
| 予算感 | 200万円以下で効果を実感したい |

### 顧客ペルソナ
> **自動車部品サプライヤーD社（従業員150名）**
> - 生産管理部門が日報集計に毎日2時間かけている
> - 発注書作成が手作業で、転記ミスが発生

1. 定型業務に時間を取られている
2. 転記ミス・人的エラーが発生
3. 「DX」と言われても何から始めればいいか分からない

### 提供価値

| 提供するもの | 顧客が得る価値 |
|-------------|---------------|
| 自動化ワークフロー | 月XX時間の工数削減 |
| エラー防止 | 転記ミス・人的エラーゼロ |
| 運用マニュアル | 社内で継続運用可能 |

| 在庫確認 | 複数システム確認 | 統合ダッシュボード | 5時間/月 |

### 成果物

1. **自動化ワークフロー**（n8n/Dify）

   - エラー検知・通知機能
   - ログ・監査機能

2. **運用マニュアル**
   - 操作手順書
   - トラブルシューティング
   - 拡張方法

3. **効果測定レポート**
   - 導入前後の工数比較
   - ROI算出

### 作業プロセス

