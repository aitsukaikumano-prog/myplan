## 概要

Anthropic Claude Cowork の活用事例を6つの系統に分類し、各50件・計300件を収集した。
情報源はnote/zenn/Qiita等の日本語ブログ、X(Twitter)投稿、YouTube、海外テック記事、Anthropic公式ドキュメント。

| # | 系統 | 件数 |
|---|------|------|
| 1 | 事務・総務系 | 50件 |
| 2 | 営業・マーケティング系 | 50件 |
| 3 | 経理・財務・法務系 | 50件 |
| 4 | クリエイティブ・コンテンツ制作系 | 50件 |
| 5 | データ分析・リサーチ系 | 50件 |
| 6 | 顧客対応・人事・教育系 | 50件 |

凡例:
- 📰 = 記事・ブログ・Xポストで確認済み
- 🔌 = 公式プラグイン/ドキュメントで確認済み
- 💡 = Coworkの機能から論理的に導出
