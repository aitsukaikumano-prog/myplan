## 練習のポイント

1. **声に出して練習** - 実際に話すと長さが分かる
2. **相手を見て話す** - 原稿を読まない
3. **ゆっくり話す** - 早口は不信感を与える
4. **数字を強調** - 「50万円」「1ヶ月」が印象に残る
5. **質問で始める** - 相手の関心を引く
