## ベンチマークとして参考になるポイント

### 1. 無料コミュニティ → 実績の流れ
asamoyaのように参加障壁を極限まで下げた無料コミュニティで人を集め、そこから講師依頼やメディア露出につなげるモデル。

### 2. 地域名×AIのブランディング
「新潟×AI」を一貫して打ち出し、検索・想起で第一位を取る戦略。我々なら「熊野町×AI」。

### 3. 低ハードルのクラファン
目標10万円という確実に達成できるラインで「支援された実績」を作る。金額よりも「地域から応援された」という事実が価値。

### 4. イベントで形に残す
AI文化祭のように、単発でも「形に残るイベント」を打つことで対外的な実績になる。

### 注意点（規模差）
新潟市（78万人）と熊野町（2.2万人）では人口規模が35倍異なる。同じスケールを目指すのは非現実的。構造（無料で集める→実績化→依頼が来る）を参考にしつつ、熊野町の規模に合った形にアレンジする必要がある。
