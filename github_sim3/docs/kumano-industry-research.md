## 1. 熊野町の概要

### 基本情報
| 項目 | 内容 |
|------|------|
| 所在地 | 広島県安芸郡熊野町 |
| 人口 | 約22,500人（2025年時点） |
| 位置 | 広島市の東南約12km、呉市の北方約10km |
| 特徴 | 海抜約250mの盆地、四方を山々に囲まれる |
| 交通 | 町内に鉄道駅なし（最寄り駅：JR呉線矢野駅） |

### 地理的特徴
- 広島市、呉市、東広島市のほぼ中心に位置
- 熊野盆地を中心に広がり、熊野川が流れる
- 中国地方で鉄道駅がない市町村では最も人口が多い

### 人口推移
- 戦前：約7,000人台
- 戦後：約9,000人台
- 昭和40年代：熊野団地建設で急増
- 1975年：20,000人突破
- 1983年：25,000人突破
- 現在：減少傾向（約22,500人）

## 2. 産業構造

### 主要産業：熊野筆

#### 概要
- **経済産業大臣指定伝統的工芸品**（1975年指定、毛筆産業では初）
- **国内シェア約80%**（川尻筆と合わせると広島県産は9割）
- 「筆の都」と称される日本最大の筆生産地
- 日本四大産地の一つ（熊野・豊橋・奈良・川尻）

#### 事業者数・従事者数
| 項目 | 数値 |
|------|------|
| 筆メーカー数 | 約100社 |
| うち化粧筆メーカー | 約10社 |
| 従事者数 | 約2,500人（町民の10人に1人） |
| 筆司 | 約1,500人 |
| 伝統工芸士 | 22人（2016年時点、4大産地で最多） |

#### 生産量
- 毛筆：年間約1,500万本（1日あたり約5万本）
- 毛筆、画筆、化粧筆のいずれも国内シェア日本一

#### 歴史
| 年代 | 出来事 |
|------|--------|
| 1835年（天保5年） | 佐々木為次が有馬で筆作りを学び、技術を熊野に持ち帰る |
| 1872年（明治5年） | 学校制度開始、筆の需要増加 |
| 1877年（明治10年） | 第1回内国勧業博覧会で入賞 |
| 1936年（昭和11年） | 年間7,000万本生産のピーク |
| 1947年（昭和22年） | GHQ学制改革で書道が必修から外される（危機） |
| 1958年（昭和33年） | 書道が小学3年生以上で必修復活 |
| 1975年（昭和50年） | 伝統的工芸品に指定 |
| 2004年（平成16年） | 団体商標取得 |
| 2006年（平成18年） | 統一ブランドマーク開発 |

#### 現在の課題
- 外国産の安価な普及品との競争
- 後継者不足（技能習得に時間を要する、単価の問題）

### 注目の若手経営者・新しい取り組み

#### 白鳳堂 - 二代目 高本壮
- 創業者・高本和男の長男
- 他業種に就職後、白鳳堂に入社
- 効率化に取り組み収益向上に成功
- 「化粧筆のエルメス」を目指す革新的な経営

#### TAUHAUS（タウハウス）
- 広島の老舗デザイン会社が参画して誕生した新ブランド
- 熊野筆の品質×デザインの融合
- 世界発信を目指す革新的な取り組み
- 従来の筆づくりに新しい価値を付加

#### 宮尾産業
- 半世紀以上続くMade in Japan化粧筆メーカー
- **2016年**: G7伊勢志摩サミットに化粧筆を出荷
- **2015年**: 日本ギフト大賞・広島県賞受賞

---

### その他の産業

**注**: 熊野町は筆産業に特化した町であり、筆以外の製造業は非常に限定的。法人数は約672件あるが、大半が筆関連または小規模なサービス業。

#### ベッドタウン機能
- 広島市安芸区と呉市に隣接
- 近年は両市のベッドタウンとして開発が進む
- 熊野団地などの住宅地開発

#### 建設業
- 熊野技建（土木・リサイクル・建築・不動産）

#### 商業・サービス業
- 地元住民向けの小売業・サービス業
- 筆関連の観光産業

#### 農業
- 農地は限られる（歴史的に農閑期の出稼ぎが筆産業のきっかけ）

#### IT・デジタル関連
- 熊野町内にはIT企業の情報なし
- デジタル化支援のニーズは高い可能性あり

## 3. 中小企業・個人事業主の状況

### 熊野町商工会
- **所在地**: 広島県安芸郡熊野町中溝4丁目17-13
- **役割**: 地域の総合経済団体、中小企業の指導団体
- **支援内容**: 伴走型小規模事業者支援推進事業

### 小規模企業の定義（商工会法）
- 製造業等：常時従業員20人以下
- 商業・サービス業：常時従業員5人以下

### 熊野町中小企業融資制度
| 項目 | 内容 |
|------|------|
| 資金使途 | 運転資金または設備資金 |
| 貸付限度額 | 1事業所につき1,500万円以内 |
| 融資期間 | 運転・設備ともに10年以内 |
| 融資利率 | 5年以内：年1.3%（保証付き1.0%）、5年超：年1.6%（保証付き1.3%） |
| 受付窓口 | 熊野町商工会 |

### AI活用支援のターゲット層
- **筆メーカー（約100社）**: 受発注管理、在庫管理、顧客管理
- **小売・サービス業**: 集客、予約管理、SNS運用
- **農業関連**: 限定的だが効率化ニーズあり

## 4. 熊野町の独自の取り組み・イベント

### 筆まつり
- **開催日**: 毎年「秋分の日」
- **場所**: 榊山神社境内・筆の里工房など
- **来場者**: 毎年約5万人
- **歴史**: 1935年（昭和10年）に第1回開催（熊野町商工会設立10周年記念）
- **由来**: 日本三筆の一人・嵯峨天皇を偲び、熊野製筆の元祖3氏（井上治平、音丸常太、佐々木為次）の功労に感謝

#### 主な催し
| イベント名 | 内容 |
|------------|------|
| 筆供養（神事） | 動物への感謝と役目を終えた筆への感謝、数千本の筆を火に投じる |
| 一万本の筆通り | 神社参道に吊り下げられた一万本の筆（熊野町のみの風景） |
| 大作席書 | 大きな作品を書く書道パフォーマンス |
| 筆の市 | 筆の販売 |
| 競書大会 | 書道コンクール |
| 彼岸船・筆踊り | 伝統的な踊り |
| ふれあいステージ | 各種パフォーマンス |

---

### 筆の里工房
- **開館**: 1994年（平成6年）9月
- **所在地**: 広島県安芸郡熊野町中溝5丁目17番1号
- **運営**: 一般財団法人筆の里振興事業団
- **開館時間**: 10:00〜17:00（入館は16:30まで）
- **休館日**: 月曜日（祝日の場合は翌日）、年末年始
- **入館料**: 大人600円、小中高生250円

#### 展示内容
- 世界一の大筆（全長3.7m、重量400kg）
- 筆の宇宙
- 木村陽山コレクション
- 熊野筆約1,500種類の販売（書筆、画筆、化粧筆）

---

### 筆の里ありがとうのちょっと大きな絵てがみ大賞
- **回数**: 第27回（2025年）
- **主催**: 一般財団法人筆の里振興事業団、中国新聞社
- **共催**: 熊野町、熊野町教育委員会
- **内容**: 絵手紙のコンクール

---

### 全国書画展覧会
- **場所**: 広島県安芸郡熊野町中溝
- **歴史**: 第93回（2025年時点）
- **関連**: ふれあい書道展（第52回、令和8年1月募集予定）
