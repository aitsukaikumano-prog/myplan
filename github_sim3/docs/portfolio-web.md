## 私の強み

### AI × 業務改善の実践経験

マツダでの業務経験で「資料作成に2ヶ月かかる作業が、本来1日で終わる」という無駄を発見。この課題意識から、AIを活用した業務効率化ツールを複数開発してきました。

### 単なる技術者ではなく、課題発見から解決までを一貫して実行

1. **課題発見**: 現場で本当に困っていることを見つける
2. **解決策設計**: AIやノーコードツールを組み合わせて最適解を設計
3. **実装・運用**: プロトタイプで終わらず、本番運用できるレベルまで構築

## 代表的な開発プロジェクト

### ゴミ分別LINEbot
「ペットボトル」「ペットボトルのキャップ」「PETボトル」—同じものでも表記が違うと検索できない問題を、**RAG + コード照合のハイブリッド設計**で解決。

→ **製造業応用**: 部品番号の表記揺れ対応、マニュアル検索の精度向上

### 業務ワークスペース
マツダで感じた「目標が曖昧」「進捗が見えない」という課題を解決するツール。AIと対話しながら目標を明確化し、進捗を可視化。

→ **製造業応用**: 目標管理システム、進捗レポート自動生成
