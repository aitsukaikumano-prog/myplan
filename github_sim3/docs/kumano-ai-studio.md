# KUMANO AI STUDIO

## ビジョン

**「暮らしている人が幸せを感じる地域を作る」**

### 幸せとは何か

生きた人間同士の継続的なコミュニティに所属し、自分を表現できること。
サークル活動のように、人と人とが実際に会って、話をして、何か楽しいことを一緒にやる。
そこに居場所がある。

AIで何もかもを効率化した無機質な社会を目指しているのではない。
効率化の先に、人と会う時間、表現する時間、楽しむ時間がある。

### そのためにKUMANO AI STUDIOがやること

自分を表現するためには、**表現する方法**と**表現する場所**が必要。

- **表現する方法の習得** — AIを使えば、自分の考えを形にしたり、新しい表現方法を見つけたり、これまでできなかったことに挑戦できる
- **表現する場所の提供** — 講座やコミュニティ活動を通じて、人と出会い、一緒に創作を楽しむ場を作る

### 活動の必須条件

KUMANO AI STUDIOの全ての活動（講座を含む）には、以下の2つが必ず含まれる：

1. **自分を表現した創作をする** — AIの使い方、作品の作り方、自分の考えの言語化
2. **人と一緒にやる** — 発表、共有、フィードバック、交流

この2つが揃って初めて、参加者にとっての「居場所」になる。

## 大切にしていること

- **人らしさを残す** — AIが作ったものは完成されすぎていて、逆に人に刺さらないことがある。人だからこその不完全さ、愚直さが人の心を動かす
- **効率化が目的ではない** — AIで仕事が楽になった分、人と会う時間、表現する時間、楽しむ時間に使ってほしい
- **体験が先、気づきは後** — まず触ってみる、やってみる。「自分はこれがやりたかった」は自然についてくる

## 活動の2本柱

| 柱 | 内容 | 目指すこと |
|---|---|---|
| **AIアート** | AIを使った作品制作・発信 | 一人一人がAIで自分を表現し、やりがいを感じる |
| **AI活用支援** | 地域の困りごとをAIで解決 | 仕事や生活がもっと楽に、もっと面白くなる |

どちらの柱も、最終的には**人と人とのつながりの場を作る**ことにつながっている。

## 目指す姿（ロードマップ）

```
① まずAIに触れてもらう（体験会）
     → 「面白い！自分にもできる！」
② AIで何かを作ってみる（名刺作り、チラシ作りなど）
     → 「自分はこれを表現したかったんだ」
③ 仲間と一緒に継続的に活動する（コミュニティ化）
     → 居場所ができる
④ 参加者同士が教え合い、挑戦し合う（社会教育グループ）
     → 熊野町がAIで活気づく
```

## 運営者

- **熊野町のAI使い**（熊野町在住）
- Web/AIエンジニア
- 「AIのことならあの人に聞こう」と思ってもらえる存在を目指している
- 費用はいただかない。地域貢献として取り組む

## 未整理のメモ

- 自分が何をしたいか、どう生きたいかを見つめることが活動参加への第一歩かもしれない → 名刺作り講座のワークとして組み込む案あり
- AIアートは「AIを使って自分を表現する」こと。表現した先に、やりがい、つながり、居場所がある
- 「AI先進町」にしたいが、人がいなくなった効率化の町ではない
- 認めてもらうことはあってもいいが、認められることを目的として創作活動をしてはいけない。大事なのは自分自身を表現した創作をすること

## ビジョン原文（大輝メモ）

> 暮らしている人が幸せを感じる地域を作りたい。
> →幸せとは、生きた人間同士の継続的なコミュニティに所属し、自分を表現し、お互いに認め合えること。（サークル活動みたいなものかな）
>
> →それを作るために、
> 人と人とが実際に会って、話をして、何か楽しいことを一緒にやる。
>
> →そのために、自分を表現する。
> →自分を表現するための方法の習得や、表現の場として講座を開設する。
>
> なので、KUMANO AI STUDIOの活動（講座も含む）は自分の表現方法を身につけることと、それを踏まえて多くの人と話をし、認めてもらうことの二つが必須の条件
>
> 効率を第一に考える、資本主義的な考え方とは一線を画す。
> 人の幸せを第一に考える、人中心主義。
>
> 認めてもらう必要はないと思ってきた。
> 大事なのは自分自身を表現した創作をすること。
> 認めてもらうことはあってもいいが、認められることを目的として創作活動をしてはいけない。
