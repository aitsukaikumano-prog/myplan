# 資料自動分類ルール

## 概要

取引先からの書類（PDF）をCoworkにドロップすると、PDFの内容を自動で読み取り、取引先名・日付・書類種別を検出してフォルダ分類・リネームを行う。

---

## フォルダ構成

```
資料自動分類/
├── {取引先名}/
│   ├── {取引先名}_{YYYYMMDD}_{種別}.pdf
│   ├── {取引先名}_{YYYYMMDD}_{種別}.pdf
│   └── ...
├── {取引先名}/
│   └── ...
└── 分類ルール.md（本ファイル）
```

**例:**

```
資料自動分類/
├── 月山酒造株式会社/
│   └── 月山酒造株式会社_20260120_領収書.pdf
├── 大和屋商店/
│   └── 大和屋商店_20260203_領収書.pdf
├── 株式会社ヴィノテラス/
│   └── 株式会社ヴィノテラス_20260125_領収書.pdf
└── はやて運送株式会社/
    └── はやて運送株式会社_20260201_領収書.pdf
```

---

## ファイル名ルール

```
{取引先名}_{YYYYMMDD}_{種別}.pdf
```

| 要素 | 説明 | 例 |
|------|------|----|
| 取引先名 | PDFから自動検出した会社名 | 月山酒造株式会社 |
| YYYYMMDD | 書類に記載された日付（8桁） | 20260120 |
| 種別 | 書類の種類 | 領収書 |

---

## 自動検出ルール

### 1. 取引先名の検出

PDFテキストから以下のパターンで会社名を検出する:

- 「株式会社」「㈱」「有限会社」「合同会社」「合資会社」を含む名称
- 発行元（PDF下部に記載される社名・住所ブロック）を優先
- 宛名（「様」の前）は自社名のため除外

### 2. 種別の検出

以下のキーワードをPDFテキストから検索:

| 種別 | 検索キーワード |
|------|---------------|
| 領収書 | 領収書、領収証 |
| 請求書 | 請求書、御請求書 |
| 見積書 | 見積書、御見積書 |
| 契約書 | 契約書 |
| 納品書 | 納品書 |

### 3. 日付の検出

以下の形式で日付を検出し、YYYYMMDD形式に変換:

- `YYYY年MM月DD日`（例: 2026年1月25日 → 20260125）
- `YYYY.MM.DD`（例: 2026.1.25 → 20260125）
- `YYYY/MM/DD`（例: 2026/01/25 → 20260125）
- `令和X年MM月DD日`（令和→西暦に変換）

---

## 使い方（Cowork）

1. Coworkのチャットにて、このフォルダを選択する
2. 分類したいPDFファイルをチャットにドロップする
3. 自動で内容を読み取り、フォルダ作成・リネーム保存が行われる
4. 複数ファイルを連続でドロップ可能

---

## 処理の流れ

```
PDFをドロップ
  ↓
pdfplumberでテキスト抽出
  ↓
取引先名・種別・日付を検出
  ↓
資料自動分類/{取引先名}/ フォルダがなければ作成
  ↓
{取引先名}_{YYYYMMDD}_{種別}.pdf としてコピー保存
  ↓
完了報告
```

---

## 注意事項

- 同一取引先の書類は同じフォルダにまとめられる
- スキャンPDF（画像のみ）はテキスト抽出できない場合がある
- 検出できなかった項目は手動で確認・補正する
- 同名ファイルが既に存在する場合は上書きに注意
