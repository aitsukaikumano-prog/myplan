### 3-2. センチメント分析

**ポジティブな反応が多いトピック:**

- **決算の「底打ち」感:** Q3単独の黒字転換により、「最悪期は脱した」との見方が市場・SNS双方で優勢。株価が決算発表日に12%超急騰したことは、関税影響を織り込んだ後の回復期待を反映している。
- **新型CX-5への期待:** 500万台達成の節目車種の8年ぶりフルモデルチェンジに対し、デザイン・走行性能への期待が高い。東京オートサロンでの行列も注目度の高さを物語る。
- **SKYACTIV-Zの独自路線:** 電動化時代にあえて内燃機関を磨くという姿勢に対し、マツダらしさを評価する声がファン層を中心に強い。

**ネガティブ・賛否両論のトピック:**

- **新型CX-5のHMI変更:** タッチパネル主体のインパネ操作に対して「マツダの従来のポリシーを捨てた」という批判的な声が一部で目立つ。物理ボタンへのこだわりがマツダの差別化要素だったため、失望感を示すユーザーも。
- **関税・リストラの連鎖懸念:** 希望退職500人は「セカンドキャリア支援」の体裁だが、「隠れリストラ」との見方が根強い。応募殺到で枠の取り合いになったことも話題に。
- **CX-3・MAZDA2の生産終了:** 小型車ラインナップの縮小を惜しむ声が多く、既存オーナーからの駆け込み注文殺到も報じられた。

### 3-3. 投資家・市場の注目ポイント

1. **米関税の行方:** 年間約2,300億円の関税コストが発生する想定で、マツダの収益構造を根本的に揺るがしている。関税が継続・強化される場合、さらなる影響は避けられない。
2. **コスト削減の進捗:** 構造的原価低減と固定費効率化で関税影響の6割超を相殺。この持続性が通期黒字達成のカギ。
3. **新型CX-5の国内投入効果:** マツダのドル箱モデルが8年ぶりのフルチェンジ。販売台数回復に直結する最重要車種。
4. **EV戦略の成否:** CX-6eは欧州CAFE規制対応の切り札。6eの販売動向がマツダの欧州事業を左右する。

### 3-5. 総括

マツダは現在、米関税という短期的な逆風と、EV化・内燃機関進化という中長期的な構造転換の二重課題に直面している。第3四半期決算では「底打ち」のシグナルが確認され、市場の評価も好転した。しかし、関税政策の不透明さは依然としてリスクであり、新型CX-5の国内投入とCX-6eの欧州展開が今後の業績回復を占う試金石となる。

X上の世論は全体として「厳しいが底は見えた」というトーンが主流。ファン層はSKYACTIV-Zや新型CX-5のデザインに期待を寄せる一方、HMIの方向転換やラインナップ縮小への懸念も根強い。投資家層は決算の市場予想上振れを好感し、下期以降の回復軌道に注目している。
