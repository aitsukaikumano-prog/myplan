## エグゼクティブサマリー

### 調査で分かったこと（3行で）

1. **製造業の課題の根本は「デジタル化の遅れ」** であり、これが人手不足・技能継承・品質問題など多くの症状を引き起こしている
2. **デジタル化が遅れる真因は「成功体験への固執」と「リスク回避文化」** という組織文化にある
3. **突破口は「小さな成功体験の創出」** であり、具体的には「熟練技能者のナレッジデジタル化」が最優先ターゲット

## 2. 自動車製造業の課題

### 業界構造の特徴

```
【自動車サプライチェーン】
  OEM（マツダ等）
      ↓
  Tier1（デンソー、アイシン等）── 営業赤字率 24%
      ↓
  Tier2 ─────────────────────── 営業赤字率 32%
      ↓
  Tier3以降 ────────────────── 営業赤字率 35%

  全68,338社のうち76%が売上10億円未満
```

### 中堅OEM（マツダ）特有の課題

| 課題 | 内容 |
|------|------|
| スケール不足 | 年間120万台 vs トヨタ1,000万台 → 投資効率で劣る |
| 電動化投資負担 | 1.5兆円規模の投資が必要だが「稼ぐ手段」が限定的 |
| ソフトウェア人材 | CASE対応に必須だが確保困難 |

### マツダの戦略的ポジション

- **「意志あるフォロワー」戦略**: EVに決め打ちせず過剰投資を回避
- **3社連携（トヨタ・スバル）**: エンジン共同開発でリソース補完
- **ライトアセット戦略**: 投資を最小化しつつ競争力維持

## 3. 根本原因分析

### 問題の5階層構造

```
【第5階層：最深層】━━━━━━━━━━━━━━━━━━━━━━━
┃  成功体験への固執  ×  リスク回避・減点主義文化   ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
                      ↓
【第4階層】意思決定の遅さ / IT=コスト観 / サイロ化
                      ↓
【第3階層】採用負け / 育成不可 / 判断できない
                      ↓
【第2階層】DX人材不足 / レガシー / 経営層無理解
                      ↓
【第1階層】★ デジタル化の遅れ ★
                      ↓
【表層】技能継承困難 / 品質問題 / 人手不足 / 競争力低下
```

### 一番ピン（最優先で解くべき課題）

| 区分 | 一番ピン |
|------|----------|
| 理論的 | 組織文化の変革（成功体験からの脱却） |
| **実践的** | **小さな成功体験の創出** |
| 具体的 | **熟練技能者のナレッジデジタル化** |

### なぜ「ナレッジデジタル化」か

| 要件 | 評価 |
|------|------|
| 経営層の痛み | ◎ 熟練者退職は待ったなし |
| 投資規模 | ◎ 数百万円でスタート可能 |
| 期間 | ◎ 3ヶ月で成果物ができる |
| 効果の可視化 | ◎ ナレッジDBという形で見える |
| 横展開 | ◎ 品質検査、予知保全へ広がる |

## 4. AIコンサルとしての攻め方

### 提案の切り口

| NG（抽象的） | OK（具体的） |
|--------------|--------------|
| 「DXを推進しましょう」 | 「熟練者の技術を残しませんか」 |
| 「AIを導入しましょう」 | 「〇〇さんの技を若手に伝える仕組みを」 |
| 「全社変革を」 | 「まず1工程で3ヶ月試しませんか」 |

### 提案ストーリー（5ステップ）

```
Step 1: 痛みへの共感
  「熟練の〇〇さん、あと2年で定年ですよね」

Step 2: 解決策の提示
  「作業動画 + AI分析でナレッジDBを作れます」

Step 3: スモールスタート
  「1工程で3ヶ月、300万円から試せます」

Step 4: 効果の可視化
  「若手の習熟期間短縮を数値で測定します」

Step 5: 横展開
  「効果が出たら他工程にも広げられます」
```
