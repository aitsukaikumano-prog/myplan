## 本文

軽量化プロジェクトチームの皆様

お疲れ様です。CAE解析課の田中です。

超高張力鋼板（1.5GPa級）の適用拡大に関するCAE解析結果をご報告いたします。

### 解析概要

現行CX-5の車体構造をベースに、1.5GPa級超高張力鋼板の適用可能部位を特定し、軽量化効果と衝突安全性能への影響を評価しました。

### 解析結果サマリー

| 評価項目 | 現行 | 最適化案 | 判定 |
|----------|------|----------|------|
| 車体重量 | 基準 | -52kg | ○目標達成 |
| 前面衝突（56km/h） | 基準 | 同等 | ○ |
| 側面衝突（50km/h） | 基準 | +5%向上 | ○ |
| ねじり剛性 | 基準 | -2% | △要検討 |

### 超高張力鋼板適用候補部位

1. **Aピラー内部補強材**: -8kg
2. **Bピラー**: -12kg
3. **ルーフレール**: -6kg
4. **フロアクロスメンバー**: -15kg
5. **リアフレーム**: -11kg

### 課題事項

1. **ねじり剛性の若干低下**
   - 対策案: サイドシル補強材の板厚微増
   - 重量影響: +2kg程度

2. **ホットスタンプ工程の追加**
   - 生産技術部門との調整が必要
   - 設備投資額の見積り依頼中

### 次のステップ

1. 1月15日: 生産技術部門との打ち合わせ
2. 1月末: 試作部品の製作依頼
3. 2月中旬: 実部品での衝突試験
