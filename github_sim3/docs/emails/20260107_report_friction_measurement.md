エンジン開発チームの皆様

お疲れ様です。潤滑技術チームの山本です。

現行SKYACTIV-Gエンジンのフリクション損失詳細測定結果をご報告いたします。

### 測定概要

| 項目 | 内容 |
|------|------|
| 対象エンジン | SKYACTIV-G 2.5L |
| 測定方法 | モータリング法 |
| 測定回転数 | 1000〜6000rpm |
| 油温条件 | 40℃、80℃、120℃ |

### 測定結果サマリー

#### 部位別フリクション寄与率（2000rpm、80℃時）

| 部位 | 寄与率 | 損失量 |
|------|--------|--------|
| ピストン・リング | 42% | 2.1kW |
| クランクシャフト | 28% | 1.4kW |
| バルブトレイン | 18% | 0.9kW |
| 補機駆動 | 12% | 0.6kW |
| **合計** | **100%** | **5.0kW** |

### 主要な知見

1. **ピストン・リング系が最大の損失源**
   - オイルリングのフリクションが特に大きい
   - リング張力最適化の余地あり

2. **低温時の損失増大が顕著**
   - 40℃時は80℃時の約1.8倍
   - 低粘度オイルの効果が期待できる領域

3. **高回転域での損失増大**
   - 5000rpm以上で急激に増加
   - バルブスプリング反力の影響大

### 改善施策案

1. **短期（〜6ヶ月）**: 低粘度オイル採用
   - 期待効果: 全体で10-15%低減

2. **中期（〜1年）**: ピストンリング仕様最適化
   - 期待効果: さらに5-10%低減

3. **長期（〜2年）**: ローラーロッカーアーム採用
   - 期待効果: バルブトレインで30%低減
