## 本文

エンジン開発チームの皆様

お疲れ様です。パワートレイン開発本部の井上です。

本日の経営会議にて、SKYACTIV-X第2世代エンジンの開発計画が正式に承認されましたのでお知らせいたします。

### 承認内容

| 項目 | 内容 |
|------|------|
| 開発コード | SX-G2 |
| 目標燃費改善率 | 現行比10%以上 |
| 圧縮着火領域拡大 | 現行比30%以上 |
| 開発期間 | 2026年1月〜2027年6月 |
| 開発予算 | 15億円 |

### 主要マイルストーン

1. **フェーズ1（〜2026年6月）**: 基礎技術開発
   - SPCCI制御精度向上
   - 冷間始動時の安定性改善

2. **フェーズ2（〜2026年12月）**: 性能検証
   - 試作エンジンでの性能確認
   - 耐久性評価

3. **フェーズ3（〜2027年6月）**: 量産準備
   - 量産仕様確定
   - 生産ライン準備

### 今後の進め方

来週1月15日（水）に開発キックオフミーティングを開催します。
詳細な開発計画と役割分担についてご説明いたします。

本プロジェクトの成功は、マツダの環境技術のリーダーシップを示す重要な機会です。
皆様のご尽力をお願いいたします。
