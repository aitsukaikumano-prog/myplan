# マルチマテリアル接合技術の量産検証開始承認

## メール情報
- **日時**: 2026-01-08 15:00
- **送信者**: 生産技術本部長 岡本浩一
- **宛先**: 生産技術部 各課長
- **CC**: 車体設計部長、品質保証部長
- **タイプ**: decision

## 本文

生産技術部 各課長

お疲れ様です。生産技術本部の岡本です。

マルチマテリアル接合技術（アルミニウム-鋼板異種材接合）の量産検証について、本日の技術審査会にて実施が承認されましたのでご報告いたします。

### 承認内容

| 項目 | 内容 |
|------|------|
| 検証対象技術 | FSW（摩擦撹拌接合）、SPR（セルフピアスリベット） |
| 適用予定車種 | 次期CX-5（2028年モデル） |
| 検証期間 | 2026年1月〜6月 |
| 検証予算 | 3億円 |

### 検証目標

1. **接合強度**: 現行溶接と同等以上（引張強度15kN以上）
2. **タクトタイム**: 60秒/箇所以内
3. **品質安定性**: Cpk 1.33以上

### 検証スケジュール

| フェーズ | 期間 | 内容 |
|----------|------|------|
| Phase1 | 1-2月 | ラボレベルでの接合条件最適化 |
| Phase2 | 3-4月 | パイロットラインでの量産性検証 |
| Phase3 | 5-6月 | 耐久性・品質検査手法の確立 |

### 組織体制

- **プロジェクトリーダー**: 生産技術部 鈴木課長
- **接合技術担当**: 溶接技術課
- **設備担当**: 設備技術課
- **品質担当**: 品質保証部

本技術の確立は、軽量化目標達成の鍵となります。
関係各位のご協力をお願いいたします。

岡本浩一
生産技術本部長
