### 試験目的

Gen2開発に向けて、現行Gen1エンジンの圧縮着火成功率と燃焼特性の詳細データを取得し、改善ポイントを明確化します。

### 試験内容

#### 1. 圧縮着火成功率マッピング

| 項目 | 条件 |
|------|------|
| エンジン回転数 | 1000〜4000rpm（500rpm刻み） |
| 負荷 | 0〜100%（10%刻み） |
| 水温 | 20℃、40℃、60℃、80℃ |
| 吸気温度 | 20℃、40℃ |

#### 2. 燃焼解析

- 筒内圧力計測（1°CA分解能）
- 熱発生率解析
- 燃焼安定性評価（COV計算）

#### 3. 排気ガス分析

- NOx、HC、CO、CO2
- 粒子状物質（PN）

### 使用機器

- エンジンダイナモ: AVL APA204
- 筒内圧センサー: Kistler 6125C
- 排気ガス分析計: HORIBA MEXA-7500D
- PN計測: AVL 489
