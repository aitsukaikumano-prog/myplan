## 本文

伊藤課長

お疲れ様です。溶接技術課の鈴木です。

マルチマテリアル接合プロジェクトの一環として、アルミニウム-鋼板接合部の電食（ガルバニック腐食）防止コーティングの耐久性試験をお願いしたくご連絡いたしました。

### 試験背景

異種金属を接合した場合、電位差によりガルバニック腐食が発生するリスクがあります。当課にて3種類の防食コーティングを選定しましたので、長期耐久性の評価をお願いいたします。

### 試験対象

| No | コーティング種類 | 膜厚 |
|----|------------------|------|
| 1 | エポキシ系接着シール | 0.5mm |
| 2 | ポリウレタン系塗料 | 30μm |
| 3 | 亜鉛リン酸被膜 | 5μm |

### 試験内容

1. **複合サイクル腐食試験（CCT）**
   - JIS H 8502準拠
   - 180サイクル（約6ヶ月相当）

2. **塩水噴霧試験（SST）**
   - JIS Z 2371準拠
   - 1,000時間

3. **実環境暴露試験**
   - 北海道（寒冷地）、沖縄（塩害地域）
   - 1年間

### 評価項目

- 腐食深さ測定
- 接合強度残存率
- 外観評価（錆、膨れ、剥離）
- 断面顕微鏡観察

### 希望スケジュール

- CCT・SST: 1月下旬開始、7月報告
- 実環境暴露: 2月開始、翌年3月報告

試験片は来週中にお届けできるよう準備中です。
ご検討のほど、よろしくお願いいたします。
