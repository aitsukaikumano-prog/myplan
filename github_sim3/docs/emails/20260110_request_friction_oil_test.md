石田課長

お疲れ様です。潤滑技術チームの山本です。

フリクション低減プロジェクトの一環として、低粘度オイル候補の耐久試験実施をお願いしたくご連絡いたしました。

### 背景

エンジン内部のフリクションロス15%低減を目標として、0W-8相当の低粘度オイルの適用を検討しています。既に摩耗試験にて3種類の候補オイルを選定しており、次のステップとして10万km相当の耐久試験が必要です。

### 試験概要

| 項目 | 内容 |
|------|------|
| 試験対象 | 低粘度オイル候補3種 + 現行オイル（比較用） |
| 試験エンジン | SKYACTIV-G 2.5L × 4基 |
| 試験時間 | 各1,000時間（10万km相当） |
| 試験条件 | 高温高負荷サイクル試験 |

### 評価項目

1. 各部摩耗量測定（カム、タペット、ピストン、ベアリング）
2. オイル劣化度分析
3. スラッジ・デポジット量
4. 金属摩耗粉分析

### 希望スケジュール

- 1月20日: 試験開始
- 3月中旬: 中間確認（500時間経過時）
- 4月末: 試験完了・報告

試験設備の空き状況と、実施可否についてご確認いただけますでしょうか。

詳細な試験計画書は添付ファイルをご確認ください。
