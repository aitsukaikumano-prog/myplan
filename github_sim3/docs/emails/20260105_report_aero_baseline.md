お疲れ様です。空力開発チームの中村です。

アクティブエアロシステム開発のベースラインとなる現行車両の空力性能測定結果をご報告いたします。

### 測定概要

| 項目 | 内容 |
|------|------|
| 対象車両 | CX-60（現行量産仕様） |
| 測定施設 | 本社風洞試験場 |
| 測定日 | 2025年12月26日 |
| 風速 | 140km/h |

### 測定結果

#### 空力係数

| 項目 | 測定値 | 備考 |
|------|--------|------|
| Cd（抵抗係数） | 0.310 | 業界平均0.32程度 |
| Cl（揚力係数） | 0.085 | フロントリフト傾向 |
| Cd×A | 0.775m² | 燃費計算用 |

#### 部位別抵抗寄与率

| 部位 | 寄与率 |
|------|--------|
| フロントグリル | 18% |
| フロントバンパー下部 | 12% |
| ドアミラー | 8% |
| ホイールハウス | 15% |
| 床下 | 22% |
| リアウインドウ〜トランク | 25% |

### 改善ポテンシャル

アクティブエアロシステム導入による改善可能性：

1. **アクティブグリルシャッター**
   - 閉時Cd: 0.295（予測）
   - 改善効果: -0.015（-5%）

2. **リトラクタブルリアスポイラー**
   - 展開時Cd: 0.305（予測）
   - 改善効果: -0.005（-1.6%）
   - 高速安定性向上効果あり

3. **アンダーカバー最適化**
   - 改善Cd: 0.300（予測）
   - 改善効果: -0.010（-3%）

### 次のステップ

1月20日からの風洞試験にて、アクティブエアロプロトタイプの効果を実測します。
