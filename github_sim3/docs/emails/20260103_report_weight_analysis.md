2026年度軽量化目標の検討に向け、現行CX-5の車体重量詳細分析結果をご報告いたします。

### 分析対象

| 項目 | 内容 |
|------|------|
| 対象車両 | CX-5 XD L Package（AWD） |
| 車両重量 | 1,680kg |
| 車体重量（BIW） | 420kg |

### 車体部位別重量内訳

| 部位 | 重量 | 構成比 | 主要材料 |
|------|------|--------|----------|
| フロアパネル | 85kg | 20% | 鋼板（440MPa） |
| サイドメンバー | 45kg | 11% | 鋼板（590MPa） |
| Aピラー | 18kg | 4% | 鋼板（980MPa） |
| Bピラー | 22kg | 5% | 鋼板（1180MPa） |
| ルーフパネル | 25kg | 6% | 鋼板（270MPa） |
| ドアパネル | 48kg | 11% | 鋼板（440MPa） |
| フード | 12kg | 3% | アルミ合金 |
| フェンダー | 8kg | 2% | 鋼板（270MPa） |
| その他構造材 | 157kg | 38% | 各種鋼板 |
| **合計** | **420kg** | **100%** | - |

### 軽量化ポテンシャル分析

| 施策 | 対象部位 | 削減量 | 備考 |
|------|----------|--------|------|
| 超高張力鋼板化 | Aピラー、Bピラー、ルーフレール | -26kg | 1.5GPa級適用 |
| アルミ化 | フェンダー、ドア外板 | -12kg | コスト増 |
| 樹脂化 | バックドア | -8kg | 塗装工程変更 |
| 構造最適化 | フロアパネル | -10kg | CAE最適化 |
| **合計** | - | **-56kg** | 目標50kg達成 |

### 課題事項

1. **コスト影響**
   - 超高張力鋼板: +3,000円/台
   - アルミ化: +8,000円/台
   - 合計: +11,000円/台

2. **生産設備投資**
   - ホットスタンプ設備: 8億円
   - アルミ溶接設備: 2億円

3. **衝突安全性**
   - CAE検証済み（田中レポート参照）
   - 実車試験で最終確認必要
