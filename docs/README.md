# 📝 ドキュメント管理

このフォルダには、プロジェクト横断の共通ドキュメントを保存します。

## フォルダ構造

```
docs/
├── meetings/      # 議事録
├── proposals/     # 企画書・提案書
└── reports/       # 分析レポート
```

## 命名規則

```
{YYYYMMDD}_{プロジェクト}_{内容}.md
```

### 例
- `20260109_brand_kickoff_meeting.md`
- `20260115_powertrain_q1_review.md`

## テンプレート

各フォルダ内の `_TEMPLATE.md` を参照してください。
