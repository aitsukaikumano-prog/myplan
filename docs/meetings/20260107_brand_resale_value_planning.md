## 📝 議事内容

### 1. リセールバリュー監視の目的確認

**発言者**: @watanabe (財務部)
**内容**:
- 中古車価格の下落はブランド価値毀損に直結
- 特にCX-5は競合が多く、価格競争に巻き込まれやすい
- 残価設定ローンの残価保証リスクも増大

**データ共有**:

| 車種 | 3年後残価率（実績） | 目標 | 乖離 |
|------|-------------------|------|------|
| CX-5 | 48% | 55% | -7pt |
| CX-60 | 52% | 55% | -3pt |
| MAZDA3 | 45% | 50% | -5pt |
| ロードスター | 62% | 60% | +2pt |

### 2. データソースの選定

**発言者**: @kimura (中古車事業部)
**内容**:
- 国内: オートオークション協議会のデータが最も信頼性高い
- 北米: Manheim Auction、CarGurus
- APIアクセスには契約が必要（年間約500万円）

**議論**:
- @daiki: 「まずは国内データから始めて、効果検証後に北米展開では」
- @watanabe: 「北米の方が市場規模大きいので、並行して進めたい」

**決定事項**:
- [ ] 国内オートオークション協議会へのAPI利用申請 → 担当: @kimura, 期限: 2026-01-15
- [ ] 北米データソースの比較表作成 → 担当: @daiki, 期限: 2026-01-20

### 3. アラートロジックの検討

**発言者**: @daiki
**内容**:
- 「標準相場」からの乖離を検知する仕組みが必要
- 乖離率5%以上で「注意」、10%以上で「警告」
- 週次レポートに加えて、リアルタイムアラートも

**議論**:
- @watanabe: 「経営層には月次サマリーで十分。週次は現場向け」
- @satoshi: 「アラート頻度が高すぎると無視される。閾値は慎重に」

**決定事項**:

| レベル | 乖離率 | 通知先 | 頻度 |
|--------|--------|--------|------|
| 通常 | ±5%以内 | - | 週次レポート |
| 注意 | 5-10% | 中古車事業部 | 即時 |
| 警告 | 10%以上 | 経営層 | 即時 |

### 4. 流通調整プロセスの設計

**発言者**: @kimura (中古車事業部)
**内容**:
- 価格下落時の対応策として：
  1. 新車インセンティブの抑制
  2. 下取り価格の見直し
  3. CPO在庫の調整
  4. 販促キャンペーンの実施

**決定事項**:
- [ ] 流通調整プロセスのフロー図作成 → 担当: @kimura, 期限: 2026-01-25
