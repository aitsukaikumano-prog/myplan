# リサーチスキル

指定されたテーマについて並列エージェントで調査し、構造化されたレポートを出力する。
テーマは `$ARGUMENTS` で渡される（例: `/research 製造業のAI活用事例`）。

## 手順

1. **調査計画の策定**
   - `$ARGUMENTS` のテーマを3〜6個のサブトピックに分解する
   - 各サブトピックに対して検索クエリを設計する

2. **並列調査の実行**
   - Taskツール（subagent_type: general-purpose）を使って3〜6個のエージェントを**並列に**起動する
   - 各エージェントには以下を指示する:
     - WebSearchで最新情報を検索
     - 信頼できるソースから情報を収集
     - 要点を箇条書きでまとめる
     - ソースURLを記録する

3. **レポート作成**
   - 全エージェントの結果を統合する
   - `github_sim3/docs/research-{テーマの英語略称}-{YYYY-MM-DD}.md` にレポートを出力する
   - レポートの構成:
     ```markdown
     # {テーマ} 調査レポート
     調査日: YYYY-MM-DD

     ## エグゼクティブサマリー
     （3-5行で全体要約）

     ## 調査結果
     ### サブトピック1
     ...
     ### サブトピック2
     ...

     ## 主要な知見
     （箇条書きで5-10項目）

     ## ソース一覧
     （URL一覧）
     ```

4. **サマリー報告**
   - レポートのエグゼクティブサマリーと主要な知見をユーザーに提示する
   - 出力ファイルパスを伝える
