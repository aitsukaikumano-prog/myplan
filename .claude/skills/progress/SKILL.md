# 進捗レポートスキル

プロジェクト全体の進捗を分析し、構造化されたレポートを出力する。

## 手順

1. **データ収集**（並列で読み込み可能）
   - `github_sim3/issues.yaml` を読み込む
   - `github_sim3/STRATEGY.md` を読み込む
   - 最近のgitログを確認する（`git log --oneline -20`）

2. **進捗分析**
   - 戦略ごとに完了率を算出する（タスクレベルで計算）
   - 直近1週間で完了したタスクを特定する
   - `in-progress` のタスクを抽出する

3. **レポート出力**
   - 以下の形式でユーザーに直接表示する（ファイル保存はしない）:

     ```
     # 📊 進捗レポート（YYYY-MM-DD）

     ## 全体進捗
     ████████░░░░░░░░ 50% (X/N タスク完了)

     ## 戦略別進捗
     | 戦略 | 完了 | 合計 | 進捗率 |
     |------|------|------|--------|
     | 1: ... | X | N | XX% |
     | 2: ... | X | N | XX% |
     | 3: ... | X | N | XX% |

     ## 直近の成果（過去7日間）
     - ✅ {タスクID}: {タイトル} (MM/DD完了)

     ## 現在進行中
     - 🟡 {タスクID}: {タイトル}

     ## 次に着手すべきタスク（推奨）
     - 🔵 {タスクID}: {タイトル} — 理由: {なぜこれが優先か}

     ## ブロッカー・懸念事項
     - {もしあれば記載}
     ```

4. **推奨タスクの選定基準**
   - 依存関係のないタスク（先行タスクが完了済み）
   - 戦略の目標達成に直結するタスク
   - 小さくて着手しやすいタスク（モメンタム維持）
