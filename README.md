# MAZDA Sync - 戦略タスク管理システム

> **GitHub + Cursor AI + WebUI で実現する、新しい仕事の仕方**

---

## 🎯 このリポジトリの目的

1. **全ての仕事データを一元管理** - タスク、資料、成果物をGitHubで管理
2. **AIとの協働** - Cursor AIがファイルを理解し、質問・資料作成に対応
3. **進捗の可視化** - WebアプリでツリーUI表示、チームで共有

## 📋 命名規則

### ファイル名の基本形式
```
{日付}_{プロジェクト}_{内容}.{拡張子}
```

### 例
| 種類 | 命名例 |
|------|--------|
| 議事録 | `20260109_brand_kickoff_meeting.md` |
| 成果物 | `2.1_A1_01_connected_data_list.xlsx` |
| 企画書 | `20260109_mymazda_integration_proposal.md` |
| レポート | `20260109_q1_progress_report.md` |

### Issue ID形式
```
{プロジェクト番号}.{戦略番号}-{カテゴリ}{連番}-{Issue連番}
例: 2.1-A1-01, 1.2-B2-01
```

## 🚀 使い方

### 1. Webアプリでタスク管理
```bash
# ブラウザで開く
open mazda-sync-app/index.html
```
- **ツリー表示**: 戦略→タスクの階層を可視化
- **タスク検索**: Issue・タスク名で検索
- **進捗確認**: プロジェクト全体の進捗率を表示

### 2. Cursor AIとの対話
| やりたいこと | Cursorで言う |
|-------------|-------------|
| タスク状態を更新 | 「CRM連携タスクを完了にして」 |
| 資料を作成 | 「データリストのExcelを作って」 |
| 検索 | 「燃費関連のタスクを教えて」 |
| 分析 | 「進捗が遅れているIssueは？」 |
| レビュー | 「この戦略に抜け漏れない？」 |

### 3. GitHubでの検索
```
# リポジトリ内でキーワード検索
path:github_sim2 CRM

# 特定ファイル形式で検索
extension:yaml completed
```

## 🔧 運用ルール

### タスク更新
1. タスク着手時 → ステータスを `in_progress` に
2. 成果物完成時 → `output/` に保存 + ステータスを `pending_approval` に
3. 承認後 → ステータスを `completed` に

### 週次ルーティン
- [ ] 月曜: 週のタスク確認、優先順位付け
- [ ] 金曜: 進捗更新、未完了タスクの棚卸し

### アーカイブ
- 完了から6ヶ月経過した成果物 → Archive保存
- 終了したプロジェクト → 別リポジトリへ移動
