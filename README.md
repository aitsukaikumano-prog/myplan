# AIビジョン・ロードマップ：大企業コンサル & 熊野町AI化計画

## 1. ビジョン (Vision)
- **大企業のAIコンサルタントとして活躍する**: 特に古巣である「マツダ」の経営課題をAIで解決し、再興の立役者となる。
- **熊野町をAI先進町にする**: 芸術（AIアート・動画・ゲーム）と実務（行政・企業の自動化）の両輪で、地方創生のAIモデルケースを作る。

## 2. ゴール (Goals)
- [ ] 3ヶ月後：熊野町でのAIセミナー・展示会の成功
- [ ] 6ヶ月後：熊野町の地元企業/役場へのAI導入実績（1件以上）の構築
- [ ] 1年後：マツダまたは同規模の大企業へのコンサルティング案件の獲得

## 3. 現状分析 (Current State)
- **技術スキル**: AI webアプリ開発、OCR、LINEボット開発が可能。
- **強み**: マツダの元社員としてのドメイン知識（内部事情・文化の理解）。
- **課題**: コンサルティング未経験。大企業を説得するための「圧倒的な実績（ポートフォリオ）」が必要。

## 4. 戦略ロードマップ
詳細は [strategy_pyramid.md](./strategy_pyramid.md) を参照。

### 🎭 変革のビジョン・ストーリー
このプロジェクトが目指す「現場の未来」をドキュメンタリー形式で描いています。
- [変革ドキュメンタリー：意志が繋がった日](./github_sim/VISION_STORY.md)

1. **【Action】最小単位の実証 (vs 佐藤工場長)**: 現場の抵抗を突破し、図面検索AIで「迷い」をゼロにする。
2. **【Local】社会的証明 (熊野町イベント)**: 「人を動かし、数字を出した」プロセスをドキュメンタリーと実績レポートで発表。
3. **【Mega】大企業コンサル (マツダ再興)**: 熊野町の実績を武器に、組織の意思決定をAIで同期する戦略コンサルを開始。

## 5. コラボレーション・ポリシー
- **忖度なしの議論**: 最良のプラン作成のため、AI（私）は客観的・戦略的観点からあえて異論を唱える場合がある。
- **目的志向**: すべての議論は「マツダの救済」と「熊野町のAI化」というゴールに直結させる。
